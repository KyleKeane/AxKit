# Workflow: Make, write, rename and delete a template in axTemplate's browser
# axTemplate's browser (docs/axTemplate/nvda-test-plan.md sections 1 to 4; SPEC TP-8, TP-2.1, TP-2.2), run by
# tools/AxAutomate on a desktop of its own (docs/axKit/automation.md). The templates' folder is the run's own home,
# empty at the start: the browser makes it and its list.json. The browser starts the launcher (TP-1.1), whose
# hotkey here is one nobody uses, so that the run never takes the user's.
file home\AxKit\axTemplate.json {"checkForUpdates": false, "hotkey": "Ctrl+Alt+Shift+F7", "sayFirstMatch": false}

start template
check commands
expect state "title":"Templates - axTemplate
expect focus No templates yet: Ctrl+N makes one

# Check: The keys are read with F1
keys f1
expect state Keyboard shortcuts
keys escape
expect focus No templates yet: Ctrl+N makes one

# Goal: Make a template
# 2.1 Ctrl+N: the template's form, empty, the focus in its name; Add makes it and selects it (TP-8.4).
keys ctrl+n
expect state "notice":"New template"
expect focus "name":"Type the title","role":"Text","value":""
type Thanks
keys enter
expect said Added Thanks
expect focus Thanks
expect state Templates, 1 template

# Check: A template without a text has nothing to copy
# 2.1a Ctrl+Enter on the new template says so; nothing is put on the clipboard.
keys ctrl+enter
expect said Thanks has no text yet: Enter opens its form

# Check: A name that is taken is refused
# 2.2 The same name again, whatever its capitals: said, and the form kept.
keys ctrl+n
type thanks
keys enter
expect said ! There is a template called thanks already
expect state "notice":"New template"
keys escape
expect focus Thanks

# Goal: Write the text of a template in its form
# 3.1 Enter on a template opens its form with every field, the focus in the name; Tab to the Text; Ctrl+Enter saves
# them all as one step (TP-8.3a, the maintainer's ask of 2026-11-23).
keys enter
expect state "notice":"Fields of Thanks"
expect focus Type the title
keys tab
expect focus Type Text; Enter makes a new line
type Thank you, {clipboard}.{caret}
keys ctrl+enter
expect said Saved Thanks. Text
expect state "notice":null

# Check: Enter on a field of the pane opens the form in that field
# 3.2 The pane is for reading: Title, Text, then the checks (TP-8.3, TP-2.2); Enter on one opens the form there,
# Escape leaves it with nothing changed, and Space turns a check on in place.
keys tab
expect focus Title
keys down
expect focus Text
keys enter
expect state "notice":"Fields of Thanks"
expect focus Type Text; Enter makes a new line
# Ctrl+Up and Ctrl+Down move between the fields of any form, the edge sound before the first (the maintainer, 2026-11-23).
keys ctrl+up
expect focus Type the title
keys ctrl+up
expect said ♪ Edge
expect focus Type the title
keys ctrl+down
expect focus Type Text; Enter makes a new line
keys ctrl+down
expect focus Check the ones that apply
# Ctrl+Space in a form: navigation mode, where the start of a field's name or its number goes to it, and Enter goes
# back to typing (AX-8.10 rule 18, the maintainer's ask of 2026-11-23).
keys ctrl+space
expect said Navigation mode
# One letter cycles from the line you are on, as in every list: from axDown to axJSON.
keys a
expect focus axJSON, not checked
keys space
expect said checked
keys 1
expect focus Type the title
keys down
expect focus Type Text; Enter makes a new line
keys enter
expect said Edit mode
expect focus Type Text; Enter makes a new line
# Check all and Uncheck all, just before the list of apps (AX-8.10 rule 19, the maintainer's ask of 2026-11-23).
keys ctrl+down
keys shift+tab
expect focus Uncheck all
keys space
expect said None checked
keys shift+tab
expect focus Check all
keys space
expect said All 5 checked
keys escape
expect state "notice":null
expect focus Text
keys down
expect focus axDown, check, not done
keys down
expect focus axJSON, check, not done
keys space
expect focus axJSON, check, done
keys escape
expect focus Thanks

# Check: Ctrl+Enter copies what the template makes
# 3.3 The marks filled with nothing (TP-8.4).
keys ctrl+enter
expect said Copied

# Goal: Rename a template
# 4.1 F2: the name in place; the file is renamed with it (TP-8.4).
keys f2
type Thank you note
keys enter
expect said Renamed Thank you note
expect focus Thank you note

# Goal: Delete a template and bring it back
# 4.2 Delete asks; Ctrl+Z brings the template back (TP-8.4).
keys delete
expect state "notice":"Delete Thank you note?"
keys enter
expect said Deleted Thank you note
expect focus No templates yet: Ctrl+N makes one
keys ctrl+z
expect said Undone: Deleted Thank you note
expect focus Thank you note

# Check: Ctrl+Z takes a rename back, the file with it
# 4.3 The name it had, and its text still there.
keys ctrl+z
expect said Undone: Renamed Thank you note
expect focus Thanks
keys tab
keys down
expect focus Text, long text, Thank you, {clipboard}.{caret}

# Goal: Rename a template from its Title field
# 4.4 Enter on the Title in the pane opens the form in its name; a new name saved renames the file (TP-8.3a, TP-8.4).
keys up
expect focus Title, text, Thanks
keys enter
expect state "notice":"Fields of Thanks"
expect focus Type the title
keys ctrl+a
type Greeting
keys ctrl+enter
expect said Saved Greeting. Title: Greeting
keys escape
expect focus Greeting
