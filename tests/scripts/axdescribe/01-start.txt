# (docs/axkit/automation.md). The screen of that desktop cannot be copied (CopyFromScreen has no screen there, "The
# handle is invalid"), so the start says that the picture could not be taken and asks nothing: the describing of a
# real window is the NVDA plan's, by ear. One description is kept beforehand, so that the list, the reopening and the
# follow-up run against the fake Claude, a cmd script in the run's own settings folder named by ai-help.json's relative
# claudePath; it swallows the prompt and prints one canned JSON answer, so the run never reaches Anthropic. The hotkey
# is one nobody uses.

# 3.1 A start on this desktop: the picture cannot be taken, said once; the window shows with its field.
start describe
expect said ! The picture could not be taken
expect focus Ask about the picture
# The window's command list: every key of its own in the F1 text, none shadowed (docs/axkit/app-kit.md AK-2.4).
check commands
expect state "status":["1 descriptions kept"

# 2.1 The kept description: Down says it with its time; Enter with nothing typed shows it again, the text first.
keys down
expect said ! 14:02 Untitled - Notepad, 1 of 1
keys enter
expect state Claude says
expect state An empty Notepad window with a menu bar.
# 2.2 Tab reaches the field for more; Enter asks in the same session and the fake answers.
keys tab
expect focus Ask more about this answer
type is anything selected
keys enter
expect state Claude says
expect state The fake answer about the picture
keys escape
expect focus "name":"Ask about the picture","role":"Text","value":""

# 2.3 A question typed in the field asks about the selected description's picture.
type what colour is the background
keys enter
expect state Claude says
keys escape
expect focus "name":"Ask about the picture","role":"Text","value":""

# 2.4 A text nothing matches: the match keys say so, with the edge; typing part of the title finds it.
type zzqq

keys ctrl+a
type notepad
keys down
expect said ! 14:02 Untitled - Notepad, 1 of 1
