# axDescribe: a picture file described (docs/axDescribe/SPEC.md DE-2.7, docs/axDescribe/nvda-test-plan.md section 4):
# a start with a picture's path describes that file at once, no picture of the screen taken (so both desktops run the
# same way, unlike 01-start.txt), and the description is kept under the file's name. The picture is a 48 by 32 PNG of
# a blue block and a red block, written here as base64 text and decoded by Windows' certutil, so the script needs no
# file of the repository (the test pictures of tests/fixtures/pictures are for the user's own tries with the real
# Claude). Claude is the fake of 01-start.txt; the run never reaches Anthropic. A file that is not a picture is
# refused before any window with a message box (AppHost.BadCommandLine), which the automation cannot drive: the unit
# tests cover the refusal.

run certutil -f -decode blocks.b64 blocks.png

# 4.1 A start with a picture: described at once, the description a notice with the text first.
start describe {temp}\blocks.png
expect state Claude says
expect state The fake description of the file
# Escape closes the description; the field is empty and has the focus.
keys escape
expect focus "name":"Ask about the picture","role":"Text","value":""
# The description is kept under the file's name, with its time.
keys down
expect said ! blocks.png, 1 of 1
# Enter with nothing typed shows it again; Tab reaches the field for more about the same file.
keys enter
expect state Claude says
keys tab
expect focus Ask more about this answer
keys escape
expect focus Ask about the picture

# 4.2 Describe a picture file... (Ctrl+D) opens the Windows file picker: a separate window, not driven here; the NVDA
# plan's step. The window's command list names it (check commands below).
check commands

# Quit axDescribe.
menu Quit axDescribe
expect closed
