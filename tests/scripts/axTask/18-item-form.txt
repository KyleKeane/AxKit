# Workflow: Change an item in its form
# axTask, docs/axTask/forms-framework.md AF-14.1, AF-14.2: Enter on an item opens its form, one standard control for
# each field of its list's configuration, in its order. Tab moves between the controls, Ctrl+Enter saves them all as
# one step for Ctrl+Z, Escape leaves and nothing is changed. Enter on a field in the detail pane opens the same form
# with the focus in that field. The detail pane stays for reading, with its one-key changes.

# Goal: Open an item's form and move through its fields
# Enter on the item: the form's sound, the focus in the title's box, ready to type, and the title with the one word
# "form" (bundle AX-7.11). The explanation is not said at opening: F7 reads it, with the values the item keeps
# that its list does not name. Tab goes through one control for each field, by its kind.
keys enter
expect state "notice":"Fields of Fix the tap"
expect focus "name":"Type the title","role":"Text","value":"Fix the tap"
expect said ♪ FormOpen
expect said Fields of Fix the tap, form
refuse said The fields of Fix the tap. Tab moves
keys f7
expect said ! The fields of Fix the tap. Tab moves
expect said 1 more field kept: Sprint
keys tab
expect focus "name":"Done"
expect focus CheckButton

keys tab

# Goal: Change several fields of an item and save them as one step
# The check checked, a date in words, a choice from its list, a text, two lines of notes, a link by the other item's
# title: Ctrl+Enter saves them together and says each once; Ctrl+Z takes all of it back in one step.
keys enter
expect focus "name":"Type the title"
keys tab
keys space
keys tab
keys ctrl+a
type 2099-11-02
keys tab
keys down down
expect focus "value":"Normal"
keys tab
keys ctrl+a
type Hall
keys tab
type First line
keys enter
type Second line
keys tab
type Washer
keys ctrl+enter
expect said ! Saved
expect state "notice":null
expect focus Fix the tap, done, due 2 November 2099
run findstr /l /c:"\"Priority\": \"Normal\"" "tasks\Home\Fix the tap.json"
run findstr /l /c:"First line\nSecond line" "tasks\Home\Fix the tap.json"
run findstr /l /c:"\"Waits on\": \"Washer.json\"" "tasks\Home\Fix the tap.json"
run findstr /l /c:"\"Sprint\": \"October\"" "tasks\Home\Fix the tap.json"
do Undo
expect said ! Undone: Saved
expect focus Fix the tap, due 30 October 2099
run findstr /l /c:"\"Room\":\"Kitchen\"" "tasks\Home\Fix the tap.json"
