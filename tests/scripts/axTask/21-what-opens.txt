# Workflow: Hear what kind of thing opened
# The bundle's AX-7.11 (the maintainer's wish of 2026-11-22), heard in axTask: whatever the user's own command opens
# in the window plays the sound of its kind first: a text to read, a field to type in, a list to choose from, a form.
# A form says its title and the word "form" and not its explanation, which F7 reads, as it reads any notice's
# text again. Options, Text, Entry sounds turns the sounds off for every window.
file tasks\Home\list.json {"format":"axkit-list 2","details":{"Notes":""},"item fields":[{"title":"Done","type":"check","value":false}],"actions":[]}
file "tasks\Home\Fix the tap.json" {"schema":"list.json","Title":"Fix the tap","Done":false}
file tasks\Later\list.json {"format":"axkit-list 2","details":{"Notes":""},"item fields":[{"title":"Done","type":"check","value":false}],"actions":[]}
start task {temp}\tasks
expect focus Your lists, heading level 1
keys down
keys right
expect focus Fix the tap

# Goal: Hear that a text to read opened
# Help, Keyboard shortcuts (F1 until 2026-11-26, the command palette now) opens the text: the text's sound, then NVDA reads the text. F7 there reads the text again.
do Keyboard shortcuts
expect state "notice":"Keyboard shortcuts"
expect said ♪ TextOpen
# A notice a menu item opens holds its keys for a second (bundle AX-6.4, E3 of the fifth review of 2026-11-27).
wait 1100
keys escape
expect state "notice":null

# Goal: Hear that a field to type in opened
# Find is one field; so is the rename box in place, F2.
keys ctrl+f
expect said ♪ FieldOpen
keys escape
expect state "notice":null
# Check: The rename box in place plays the same sound
keys f2
expect focus "name":"New name"
expect said ♪ FieldOpen
keys escape
expect focus Fix the tap

# Goal: Hear that a form opened, and its explanation only on demand
# Ctrl+M on an item: the form's sound, the focus in its list, then "Move Fix the tap, form". F7 reads the
# explanation; it is not said at opening.
keys ctrl+m
expect state "notice":"Move Fix the tap"
expect said ♪ FormOpen
expect said Move Fix the tap, form
refuse said Up and Down choose the list
keys f7
expect said ! Now in Home. Up and Down choose the list
keys escape
expect state "notice":null
