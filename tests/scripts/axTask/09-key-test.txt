# Workflow: Find out whether a key arrives and what it does, in an item window
# axTask: Help, Diagnostics, Test a key (docs/axKit/SPEC.md AX-8.12). Every key is said with what it does where the
# focus is, the navigator here, and none is carried out; Escape ends it. Ctrl+Up and Ctrl+Down are the item
# windows' section keys in the navigator, in the bundle's paragraph keys' place (docs/axKit/item-apps.md IA-2.3a).
file tasks\Shopping\list.json {"format":"axkit-list 2","details":{"Notes":""},"item fields":[{"title":"Done","type":"check","value":false}],"actions":[]}
file tasks\Shopping\Milk.json {"schema":"list.json","Title":"Milk"}
file tasks\Shopping\Washer.json {"schema":"list.json","Title":"Washer","Done":false}

start task {temp}\tasks
expect state "title":"Lists, axTask
type s
expect focus Shopping, list, 2 items
keys right
expect said ! Shopping, 2 items, Milk
expect commands "Test a key, Help, Diagnostics"
# Goal: Test what a key does
menu Test a key
expect said ! Key test. Press any key to hear its name and what it does here. Press Escape to end.

keys f9
expect said ! F9: Say the status
# Check: The bundle's keys, the window's keys and a key nothing has are each said by what they do
keys f1
expect said ! F1: Command palette
# The bundle's two keys on Ctrl and punctuation (AX-8.15), named by the keys they stand beside.
keys ctrl+period
expect said ! Ctrl+Period: The Context menu, as Shift+F10
keys ctrl+slash
expect said ! Ctrl+Slash: Ask Claude about this window, as Shift+F1
keys ctrl+n
expect said ! Ctrl+N: New item
keys ctrl+up
expect said ! Ctrl+Up: Previous section
keys left
expect said ! Left: Up a level
keys down
expect said ! Down: moves in the list
keys w
expect said ! W: finds the next item that starts with what you type
keys shift+f9
expect said ! Shift+F9: no command of this window
# Check: Nothing is carried out during the key test
# Nothing was carried out: the same list, the same item, no notice.
expect state "notice":null
expect state "title":"Shopping, axTask
expect focus "value":"Milk"

# Goal: End the key test
# Escape ends the test at once, and leaves the list as it was.
keys escape
expect said ! Key test ended
expect state "title":"Shopping, axTask

# Check: The keys act again after the test
# The same keys act again.
keys w
expect focus "value":"Washer"
keys left
expect said ! Lists
