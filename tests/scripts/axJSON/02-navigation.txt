# Workflow: Move through a JSON file by its structure
# axJSON, test plan section 2 (Navigation, AJ-2.2), driven from inside the window (docs/axJSON/nvda-test-plan.md).
# The run's own settings: no update check, whose network call logs an ERROR when GitHub cannot be reached.
file settings.json {\n  "model": "opus",\n  "permissions": { "allow": ["Bash", "Read"], "deny": [] },\n  "count": 3,\n  "on": true\n}
file missing-value.json {\n  "model": "opus",\n  "permissions": { "allow": ["Bash", "Read"], "deny": [] },\n  "count": ,\n  "on": true\n}
file broken.json {\n  "model": "opus"\n  "permissions": { "allow": ["Bash", "Read"], "deny": [], },\n  "count": 3,\n  "on": true\n}

start json {temp}\settings.json
expect focus settings.json

# Goal: Move from key to key
# 2.1: Ctrl+K from the top, each key with its value or its container; then "No next key", the caret staying.
keys ctrl+k
expect said ! model: opus
expect state Line 2, Column 3 \u00B7
# Check: Each press goes on to the next key with its value or its container
keys ctrl+k
expect said ! permissions, object with 2 keys
keys ctrl+k
expect said ! allow, array with 2 items
keys ctrl+k
expect said ! deny, empty array
keys ctrl+k
expect said ! count: 3
keys ctrl+k
expect said ! on: true
expect state Line 5, Column 3 \u00B7
# Check: After the last key No next key is said and the caret stays
keys ctrl+k
expect said ! No next key
expect state Line 5, Column 3 \u00B7
# Goal: Move back from key to key
# Ctrl+Shift+K back the same way; at the top "No previous key".
keys ctrl+shift+k
expect said ! count: 3
# Check: Each press goes back one key, to the first
keys ctrl+shift+k
expect said ! deny, empty array
keys ctrl+shift+k
expect said ! allow, array with 2 items
keys ctrl+shift+k
expect said ! permissions, object with 2 keys
keys ctrl+shift+k
expect said ! model: opus
# Check: Before the first key No previous key is said
keys ctrl+shift+k
expect said ! No previous key

# Goal: Move to the next object and back to the whole file
# 2.2: Ctrl+J, the object of permissions, then none; Ctrl+Shift+J back to the whole file, the caret on its first brace.
keys ctrl+home ctrl+j
expect said ! permissions, object with 2 keys
# Check: After the last object No next object is said, and the whole file is one step back
keys ctrl+j
expect said ! No next object
keys ctrl+shift+j
expect said ! object with 4 keys
expect state Line 1, Column 1 \u00B7
# 2.2, Ctrl+Home then Ctrl+J on the whole file: at the end of this script, since it fails (see the report).

# Goal: Move through arrays and their items
# 2.3: arrays and items.
keys ctrl+home ctrl+l
expect said ! allow, array with 2 items
keys ctrl+l
expect said ! deny, empty array
# Goal: Move from item to item of an array
keys ctrl+home ctrl+i
expect said ! Item 1 of 2, Bash
keys ctrl+i
expect said ! Item 2 of 2, Read
# Check: After the last item No next item is said
keys ctrl+i
expect said ! No next item

# Check: A valid file has no next error
# 2.4: Ctrl+E in a valid file: "No next error".
keys ctrl+home ctrl+e
expect said ! No next error

# Check: Plain arrow keys speak nothing of axJSON's own
# 2.6: plain arrow keys speak nothing of axJSON's own.
keys down down right right left up end home
expect quiet 1000

# Goal: Move by the structure from the Navigation menu
# 2.5: Navigation, Next and Previous list Key, Object, Array, Item and Error with their keys; each item does what its key does.
expect commands "Key, Navigation, Next, Ctrl\u002BK"
expect commands "Object, Navigation, Next, Ctrl\u002BJ"
expect commands "Array, Navigation, Next, Ctrl\u002BL"
expect commands "Item, Navigation, Next, Ctrl\u002BI"
expect commands "Error, Navigation, Next, Ctrl\u002BE"
expect commands "Key, Navigation, Previous, Ctrl\u002BShift\u002BK"
expect commands "Object, Navigation, Previous, Ctrl\u002BShift\u002BJ"
expect commands "Array, Navigation, Previous, Ctrl\u002BShift\u002BL"
expect commands "Item, Navigation, Previous, Ctrl\u002BShift\u002BI"
expect commands "Error, Navigation, Previous, Ctrl\u002BShift\u002BE"
keys ctrl+home
menu Key, Navigation, Next
expect said ! model: opus
# Check: Each item of Next and Previous does what its key does
menu Object, Navigation, Next
expect said ! permissions, object with 2 keys
menu Array, Navigation, Next
expect said ! allow, array with 2 items
menu Item, Navigation, Next
expect said ! Item 1 of 2, Bash
menu Item, Navigation, Previous
expect said ! No previous item
menu Array, Navigation, Previous
expect said ! allow, array with 2 items
menu Object, Navigation, Previous
expect said ! permissions, object with 2 keys
menu Object, Navigation, Previous
expect said ! object with 4 keys
menu Key, Navigation, Previous
expect said ! No previous key
menu Error, Navigation, Next
expect said ! No next error
menu Error, Navigation, Previous
expect said ! No previous error
# Check: The structure keys move in the user guide's text too
# Help, User guide: Ctrl+K and the other keys move through the guide's text too, "No next key" when there is none.
menu User guide
expect state "notice":"User guide"
keys ctrl+k
expect said ! No next key
# A notice a menu item opens holds its keys for a second (bundle AX-6.4, E3 of the fifth review of 2026-11-27).
wait 1100
keys escape
expect focus settings.json

# Goal: Go to the next and the previous error
# 2.4: broken.json. Its two faults are the forgiving outline's repairs (SPEC.md AJ-2.2: a missing comma between members
# and a trailing comma read as JSON; scenario 2), so Ctrl+E says "No next error" there; the plan's error on line 3 is
# from before that rule. The error itself is checked on a value that is missing, the spec's other example.
start json {temp}\broken.json
expect focus broken.json
keys ctrl+home ctrl+e
expect said ! No next error
start json {temp}\missing-value.json
expect focus missing-value.json
keys ctrl+home ctrl+e
expect said ! Error, line 4: expected a value, found ','
expect state Line 4, Column 12 \u00B7
keys ctrl+end ctrl+shift+e
expect said ! Error, line 4: expected a value, found ','
expect state Line 4, Column 12 \u00B7

# Check: On the first brace the next object is the one after the caret
# 2.2: Ctrl+Home, Ctrl+J: the object after the caret, since the caret on the first brace is on the whole file already
# (AJ-2.2, as axDown's headings); Ctrl+Shift+J from inside reaches the whole file.
use 1
keys ctrl+home ctrl+j
expect said ! permissions, object with 2 keys
keys ctrl+shift+j
expect said ! object with 4 keys
