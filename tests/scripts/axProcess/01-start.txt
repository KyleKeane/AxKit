# Workflow: Find and end a process
# axProcess: start, the Processes view, ending a process (docs/axProcess/nvda-test-plan.md sections 1 and 2; SPEC PR-2, PR-3).
# The lists are this computer's, so the steps match the fixed words, never a count. The script ends something in the
# list, so it ends only what it started itself, under a name no other program has: a copy of Windows' own ping, made
# in the run's folder as axkitscript01.exe, which asks this computer itself for 120 echoes (two minutes, nothing
# leaves the computer) with its window hidden. Nothing else is ever selected for an end: the text typed into Find is
# the copy's own name, the row must be it before Delete, the question must name it, and a script stops at its first
# failing step (until 2026-11-21 the script found "PING", which another ping on the computer would have answered
# to). It is started apart from the runner's command (run's own children end with the command, since it reads
# their output), and named with its folder (.\), since a command prompt may be set not to look in the folder it is in.
run copy /y %SystemRoot%\System32\PING.EXE axkitscript01.exe
run powershell -NoProfile -Command "Start-Process '.\axkitscript01.exe' -ArgumentList '-n','120','127.0.0.1' -WindowStyle Hidden"

# Check: The window opens with the processes' list named and said
# 1.1 The window, and after the first read (one second of sampling) the list's name and first item, not interrupting.
start process
# The window's command list: every key of its own in the F1 text, none shadowed (docs/axKit/app-kit.md AK-2.4).
check commands
expect state "title":"axProcess This computer
# The list is named "Processes, reading" while the first read runs; the status bar says "Reading…" until it is done.
expect state "status":["Processes,
expect said Processes,
expect focus Processes,

# Check: The status bar holds the list's name and the memory in use
# 1.3 The status bar: the list's name and the memory in use.
expect state "status":["Processes,
expect state % in use
# The list is read and a process is selected: the context menu now holds the process's commands, which the snapshot
# at the start (taken while the first read ran) may not have seen (the NVDA pass of 2026-11-16).
check commands

# Goal: Hear how much memory is in use
# 1.4 F7: the summary.
keys f7
expect said GB in use

# Check: Nothing is said while no key is pressed
# 1.5 Nothing is said while no key is pressed: the list never refreshes by itself (PR-D2).
expect quiet 3000

# Goal: Refresh the list
# 1.6 F5: read again, said, the selection kept.
keys f5
expect said ! Refreshed: Processes,

# Goal: Sort the processes by name, processor or memory
# 2.1 Sort by name, by processor, back to memory, each said.
menu Name
expect said ! Sorted by name
menu Processor
expect said ! Sorted by processor
menu Memory
expect said ! Sorted by memory

# Goal: Find a process and read its details
# 2.2 Ctrl+F finds the script's own copy of ping by its name; Enter shows its details with the buttons; Escape closes them.
keys ctrl+f
expect state Find
type axkitscript01
keys enter
expect focus "value":"axkitscript01,
keys enter
expect state "notice":"axkitscript01"
expect state Process ID
expect state Memory
keys escape
expect state "notice":null
expect focus "value":"axkitscript01,

# Check: Closing the question keeps the process running
# 2.5 Delete asks, Escape keeps it; Delete and Enter end it, and the list is read again without it.
keys delete
expect state End axkitscript01 (process
expect state Anything unsaved in it is lost.
# A notice holds its answering keys for a moment after it appears (KeyHold).
wait 1200
keys escape
expect state "notice":null
expect focus "value":"axkitscript01,
# Goal: End a process
# Ctrl+Enter, the main action, is End process on a process, with the question Delete asks (PR-6.2, 2026-11-26).
keys ctrl+enter
expect state End axkitscript01 (process
wait 1200
keys enter
expect said ! Ended axkitscript01
refuse list axkitscript01,

# Check: Saving says there is nothing to save
# 2.8 Ctrl+C copies the line: the clipboard is shared with the user's session, so the step is not run (automation.md).
# Ctrl+S: nothing to save, and what the keys do said.
keys ctrl+s
expect said ! Nothing to save here. F5 refreshes, Delete ends a process
