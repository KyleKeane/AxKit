# Workflow: Manage services and startup programs
# axProcess: the Services and Startup views (docs/axProcess/nvda-test-plan.md sections 3 and 4; SPEC PR-4, PR-5).
# Read only: no service is started or stopped here, since a run with administrator rights would do it for real.
file home\AxKit\axProcess.json {"checkForUpdates": false}
# In a test run the Startup view reads a stand-in of the run's own, never this computer's start-up places (PR-5.8):
# one file in the run's stand-in for your Startup folder, so that the view has an entry.
file home\AxKit\startup\yours\Morning.lnk a stand-in for a shortcut
start process
# The first read done: the status bar says "Reading…" until then, and a view key meanwhile says "Working…" (PR-2.3).
expect state "status":["Processes,

# Goal: Show the services
# 3.1 Alt+2: the services, said with the first one; every Windows has the event log running.
keys alt+2
expect said ! Services,
expect focus Services,

# Goal: Read a service's details
# 3.2 Its details: the name, the state, the start type; Escape closes them.
keys ctrl+f
expect state Find
type (EventLog)
keys enter
expect focus Windows Event Log (EventLog), running
keys enter
expect state "notice":"Windows Event Log"
expect state Name EventLog
expect state State running
keys escape
expect state "notice":null

# Check: Delete, Show program and Space on a service say why they do not act
# 3.3 A service is not ended, has no program to show here and is not selected; each key says so.
keys delete
expect said ! A service is not ended: Enter shows it, with Stop where it can be stopped
keys ctrl+e
expect said ! Show program is for a process or a startup program
keys space
expect said ! Services are not selected: nothing here acts on several of them

# Goal: Go back from the services to the processes
# 3.4 Alt+2 again names the view; Alt+1 back to the processes.
keys alt+2
expect said ! Services,
keys alt+1
expect said ! Processes,

# Check: The older keys of the views still work
# 3.4a Ctrl+1, Ctrl+2 and Ctrl+3, the views' keys until 2026-11-16, still switch the view, with nothing more said.
keys ctrl+2
expect said ! Services,
keys ctrl+3
expect said ! Startup, 1.
keys ctrl+1
expect said ! Processes,

# Goal: Show the startup programs
# 4.1 Alt+3: the startup programs: the run's stand-in, with its one entry (until 2026-11-14 this computer's own, whatever
# it starts).
keys alt+3
expect said ! Startup, 1. Morning, enabled, your Startup folder
expect focus Startup, 1

# Goal: Read the keyboard shortcuts
# 5.3 F1: the shortcuts; Escape.
keys f1
expect state "notice":"Keyboard shortcuts"
expect state Alt+1, Alt+2, Alt+3
keys escape
expect state "notice":null

# Goal: Go up to This computer and into another list
# 2.2 The three lists are rows of This computer (docs/axKit/framework.md FW-4.6): Left goes up, onto the list left,
# and at the top plays the edge sound; Right, or Enter, goes into the list you are on; Backspace is Left.
keys alt+1
expect said ! Processes,
keys left
expect said ! This computer, 3 lists, Processes,
keys left
expect said ♪ Edge
keys down
expect focus Services,
keys right
expect said ! Services,
keys backspace
expect said ! This computer, 3 lists, Services,
keys end
expect focus Startup,
keys enter
expect said ! Startup,

# Check: Only the menu of the view shown is enabled
# 6.1 Only the menu of the view shown is enabled: no service command among the startup programs, no process command
# among the services (the palette's list is the menus' enabled items).
refuse commands Restart
refuse commands End process tree
expect commands Turn off
keys alt+2
expect said ! Services,
expect commands Restart
refuse commands End process tree

# Check: Moving past either end of the list plays the edge sound
# 2.6 Up on the first item and Down on the last: the edge earcon, nothing said.
keys home
keys up
expect said ♪ Edge
keys end
keys down
expect said ♪ Edge

# Goal: Find a service by typing its name
# AX-8.6 Type-to-find in the services: a prefix lands on its item; Shift with the letter goes back the other way.
keys alt+2
expect said ! Services,
type windows event l
expect focus Windows Event Log (EventLog)
# Check: A letter typed at the last item goes round to the first name with it
# From the last item a letter goes round the end to the first name with it. Shift with a letter (backwards) is not run:
# the channel's keys make no typed character, and its type has no Shift; TypeAheadTests and the NVDA plan cover it.
keys end
wait 1100
type w
expect focus "value":"W
