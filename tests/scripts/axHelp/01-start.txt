# 1.1 axHelp's window: one read-only text that names the two hotkeys; the command list names every key (AK-2.4).
start help
check commands
expect focus "name":"axHelp","role":"Text"
expect state "title":"axHelp hotkeys"

# Goal: Turn on the AI tools
# HE-2.8: the AI tools turned on, as the user does it (asked once; a test run never touches Claude Code's settings),
# so that the conversation below gets them by itself: axClaude writes the file that names this AxKit.exe and starts
# Claude Code with --mcp-config. Off, as in 02-hide-and-show.txt, no file is written and nothing is added.
menu Let AI tools read and open axKit
expect state "notice":"Turn on AI tools?"
keys enter
expect said AI tools on
try said Not in a test run

# Goal: Open a conversation with Claude
# 2.1 Enter: the conversation, a new axClaude window titled axHelp, the focus in its message field once Claude is ready.
keys enter
adopt
try said trust
iffound wait 1500
iffound keys enter
expect said Ready
expect state "title":"axHelp"
expect focus "name":"Message to Claude"
# Check: The conversation's folder holds its guides, its rules and the tools' file
# The working folder's two files were written before the start (HE-2.4).
run dir /b "home\axKit Claude\CLAUDE.md" "home\axKit Claude\.claude\agents\agent.md"
# axKit's guides too (HE-2.6): the index, the bundle's guide, an app's, the marker, and the rule that tells Claude of them.
run dir /b "home\axKit Claude\documentation\index.md" "home\axKit Claude\documentation\axKit.md" "home\axKit Claude\documentation\axFile.md" "home\axKit Claude\documentation\axkit-version.txt" "home\axKit Claude\.claude\rules\axkit-documentation.md"
# The pages Claude answers how-to questions from (docs/axKit/user-workflows.md WF-8.1): the workflows' index, an app's
# workflows, every window's commands, and the two key pages.
run dir /b "home\axKit Claude\documentation\workflows.md" "home\axKit Claude\documentation\workflows-axFile.md" "home\axKit Claude\documentation\window-commands.md" "home\axKit Claude\documentation\key-groups.md" "home\axKit Claude\documentation\key-map.md" "home\axKit Claude\documentation\families.md" "home\axKit Claude\documentation\cases.md" "home\axKit Claude\documentation\outside-calls.md" "home\axKit Claude\documentation\privacy.md" "home\axKit Claude\documentation\changelog.md"
# The rule that tells Claude when to use which of axKit's AI tools (HE-2.8), every tool named in it, and the file
# Claude Code was started with, which names this run's AxKit.exe as the server axkit.
run dir /b "home\axKit Claude\.claude\rules\axkit-tools.md" "home\AxKit\claude-mcp.json"
run findstr /c:"### axkit_window_run" "home\axKit Claude\.claude\rules\axkit-tools.md"
run findstr /c:"\"axkit\"" "home\AxKit\claude-mcp.json"
# Alt+F4 would only hide this window (HE-1.3; 02-hide-and-show.txt): its own command ends it, for a fresh start below.
menu End Claude and close this window
expect closed

# Goal: Hand a picture to a new conversation
# 3.3 A start with a picture while axHelp runs: the picture's path into a new conversation's message field.
launch help {temp}\blocks.png
adopt
try said trust
iffound wait 1500
iffound keys enter
expect said Ready
expect focus "name":"Message to Claude"
expect focus Picture blocks.png:
# Check: A second picture is added to the open message, and the window says so
# A second picture while the conversation is open goes into its message field, and the window says so, since the
# text arrived from outside it (docs/axKit/repairs.json R-07).
said
launch help {temp}\blocks.png
expect said Text added to your message from another window, not sent

# Goal: Quit axHelp
# Quit axHelp, the one close that ends its process. The conversation is asked to end with it (HE-1.3) and, holding
# the pictures' lines unsent, asks first; Close anyway ends it.
use 1
menu Quit axHelp
expect closed
use 3
expect state "notice":"Close this conversation?"
wait 1500
keys tab
expect focus Close anyway
keys enter
expect closed
