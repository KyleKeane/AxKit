# Workflow: Start a terminal
# axTerminal, section 1 of docs/axTerminal/nvda-test-plan.md: start (AT-1, AT-2). The shell is the default one of a
# fresh settings file: PowerShell 7 when installed, otherwise Windows PowerShell; the texts below name neither.
# Plan step 1 by the Start menu entry stays manual: the Start menu is the system's, outside the window.
# NVDA's own reading of the window's name on opening is tier 3 (NVDA in the loop); here the title is checked.
mkdir myproject
# The run's own settings: no update check, which would go to the network and log an ERROR when it fails.
file home\AxKit\axTerminal.json {"checkForUpdates": false}
# The access layers' reminders agreed to already (AX-11.5): this script is about what comes after them.
file home\AxKit\consent.json {"items":[{"app":"axClaude","target":"Claude Code","version":"0","when":"2026-10-31T00:00:00"},{"app":"axGIT","target":"Git","version":"0","when":"2026-10-31T00:00:00"},{"app":"axTerminal","target":"Windows PowerShell","version":"0","when":"2026-10-31T00:00:00"},{"app":"axTerminal","target":"PowerShell 7","version":"0","when":"2026-10-31T00:00:00"},{"app":"axTerminal","target":"Command Prompt","version":"0","when":"2026-10-31T00:00:00"},{"app":"axTerminal","target":"Git Bash","version":"0","when":"2026-10-31T00:00:00"},{"app":"axPass","target":"KeePassXC","version":"0","when":"2026-10-31T00:00:00"}]}
start terminal {temp}\myproject
# Check: The window's command list holds every key of its own
# The window's command list: every key of its own in the F1 text, none shadowed (docs/axKit/app-kit.md AK-2.4).
check commands
# Check: The window opens on the command field and says Ready
# Step 1: the window and the field; after a moment the ping and "Ready".
expect focus Command
expect state "title":"axTerminal, access layer for your shell folder 
expect state "title":"axTerminal, access layer for your shell folder 
expect said Ready
expect said ♪ Ready

# Goal: Move between the command field and the terminal
# Step 2: Alt+2 lands on the terminal; its first lines are the system line and PowerShell's PSReadLine line; no
# prompt row. Alt+1 back to the field.
do Terminal
expect said → Terminal
expect focus Terminal
expect text "System: Shell started:
expect text PSReadLine
# That no prompt row ("PS C:\...>") is in the text cannot be checked: the runner has no "refuse text".
do Terminal
expect said ! Terminal
do Command field
expect said → Command
do Command field
expect said ! Command

# Check: Alt and a number reaches the window from the command field and from the terminal
# Step 2a: the keys themselves, pressed in the field and in the terminal: Alt+2, Alt+1, and Alt+3, which says that
# there is no output yet and goes to the terminal.
keys alt+2
expect said → Terminal
expect focus Terminal
keys alt+2
expect said ! Terminal
keys alt+1
expect said → Command
expect focus Command
keys alt+3
expect focus Terminal
keys alt+1
expect focus Command

# Check: The older keys of the places still work
# Step 2b: Ctrl+1, Ctrl+2 and Ctrl+3, the places' keys until 2026-11-16, still go there, with nothing more said.
keys ctrl+2
expect said → Terminal
keys ctrl+2
expect said ! Terminal
keys ctrl+3
expect focus Terminal
keys ctrl+1
expect said → Command
expect focus Command

# Check: The status bar holds Idle and the prompt
# Step 3: the status bar holds "Idle" and the prompt text. The state answer is raw JSON, where a backslash is
# doubled and ">" is written \u003E, so the prompt is matched by its ends.
expect state "status":["Idle","PS
expect state myproject\u003E"]

# Goal: Hear the state, the shell and the prompt
# Step 4: Ctrl+Q says the state, the shell and the prompt.
do What is running
expect said PowerShell, PS {temp}\myproject>
