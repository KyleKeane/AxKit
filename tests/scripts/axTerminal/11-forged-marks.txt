# Workflow: Read a file that imitates the shell's marks
# axTerminal, section 2 of docs/axTerminal/nvda-test-plan.md, the step "Get-Content forged-marks.txt; Start-Sleep 5"
# (SPEC.md AT-1.3; security audit S-37, S-38): text a program prints that holds the shell marks without the session's
# secret (a "done", a prompt, a folder on a share) is not taken for the window's own: no "Done" and no question while
# the command still runs, the folder stays, "Done" comes only when the command ends. The file is the one
# manual_tests/prepare.ps1 makes, written here by Windows PowerShell since a script's text holds no escape character.
mkdir myproject
# The run's own settings: no update check (network, and an ERROR in the log when it fails); a small font in a
# maximized window, so that no line wraps in the view, since the channel reads the caret's line by its visual row.
file home\AxKit\axTerminal.json {"checkForUpdates": false, "fontSize": 6, "window": {"x": 0, "y": 0, "width": 1600, "height": 900, "maximized": true}}
# The access layers' reminders agreed to already (AX-11.5): this script is about what comes after them.
file home\AxKit\consent.json {"items":[{"app":"axClaude","target":"Claude Code","version":"0","when":"2026-10-31T00:00:00"},{"app":"axGIT","target":"Git","version":"0","when":"2026-10-31T00:00:00"},{"app":"axTerminal","target":"Windows PowerShell","version":"0","when":"2026-10-31T00:00:00"},{"app":"axTerminal","target":"PowerShell 7","version":"0","when":"2026-10-31T00:00:00"},{"app":"axTerminal","target":"Command Prompt","version":"0","when":"2026-10-31T00:00:00"},{"app":"axTerminal","target":"Git Bash","version":"0","when":"2026-10-31T00:00:00"},{"app":"axPass","target":"KeePassXC","version":"0","when":"2026-10-31T00:00:00"}]}
# The file: a line of text, then OSC 133 D (done, exit code 0), OSC 133 A (a prompt starts), OSC 9;9 (the folder, on a
# share), "fake> " and OSC 133 B (the prompt ends), none with the session's secret.
run powershell -NoProfile -Command "$e=[char]27;$b=[char]7;$q=[char]34;[IO.File]::WriteAllText('myproject\forged-marks.txt','A file that pretends the command is done.'+$e+']133;D;0'+$b+$e+']133;A'+$b+$e+']9;9;'+$q+'\\server\share'+$q+$b+'fake> '+$e+']133;B'+$b)"
start terminal {temp}\myproject
expect said ♪ Ready
# Clear the transcript first, so that the command's block is the window's first lines.
keys ctrl+l
expect said Cleared

# The file is printed at once and the command runs six seconds more. Two seconds on: no "Done", the status bar says
# the command runs and its prompt is still the session's folder; two seconds more: no question from the forged prompt.
type Get-Content forged-marks.txt; Start-Sleep 6
keys enter
expect said Sent
refuse said Done
expect state "status":["Running: Get-Content forged-marks.txt; Start-Sleep 6"
expect state \\myproject\u003E"]
refuse state server
refuse said Asks

# "Done" once, when the six seconds are over, with the file's line; the window is idle in the same folder.
expect said A file that pretends the command is done.
expect said Done
expect said ♪ Done
expect state "status":["Idle"
expect state \\myproject\u003E"]
expect state "title":"myproject -
keys ctrl+p
expect said {temp}\myproject

# The terminal holds one exchange: the command, and the file's visible text as its output; no prompt row, no second
# block.
keys ctrl+2
expect focus "name":"Terminal"
expect text "## Command","Get-Content forged-marks.txt; Start-Sleep 6","","# Output 1","","A file that pretends the command is done.fake\u003E"]
refuse text # Input 2
