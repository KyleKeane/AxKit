# Workflow: Start a shell in a recent folder from the command palette
# axTerminal, section 3 of docs/axTerminal/nvda-test-plan.md, "Session, Open recent folder: the folders as
# 1. name (path); Enter on one: a new session there" (SPEC.md AT-6, "Folder <name>"). The submenu needs menu mode,
# which only the foreground window enters; since 2026-11-13 the command palette reads every Open recent list
# (docs/axKit/SPEC.md AX-10.2), so the entry is one search away: Ctrl+Shift+P, part of the name, Enter.
mkdir work\orchard
mkdir work\cellar
# The run's own settings: no update check, which would go to the network and log an ERROR when it fails.
file home\AxKit\axTerminal.json {"checkForUpdates": false}
# The access layers' reminders agreed to already (AX-11.5): this script is about what comes after them.

# window on the second, which lists both, the newest first.
