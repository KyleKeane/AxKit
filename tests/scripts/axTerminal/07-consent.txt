# Workflow: Agree to the reminder before a shell first starts
# axTerminal: the reminder before a shell first starts (docs/axKit/SPEC.md AX-11.4, AX-11.5; the Owed list of
# docs/axKit/nvda-test-record.md). Each shell is its own consent; the default shell here is Windows PowerShell or
# PowerShell 7, so the texts name neither. With --nvda (nvda-pass.ps1) every expected line must be spoken by NVDA too.
mkdir myproject
start terminal {temp}\myproject

# Goal: Agree to the reminder and start the shell
expect said Before axTerminal connects to
keys tab
expect said I understand that axTerminal
keys enter
expect said ! Check the box first
keys space
expect said ! checked
keys space
expect said ! not checked
keys space
expect said ! checked
# Enter connects: the shell starts and says Ready.
keys enter
expect said Ready

# Check: Each shell asks its own reminder
# Each shell is its own consent: a new session with Command Prompt asks its reminder, then starts.
do New session
expect state "notice":"New session"
keys tab
expect focus folder..."}
keys tab
expect focus "role":"RadioButton"
keys down
expect focus "value":"Command Prompt"}
keys enter
expect said Before axTerminal connects to Command Prompt
keys tab
expect said I understand that axTerminal
keys space
expect said ! checked
keys enter
expect said Ready
close

# Check: The second start asks nothing
# The second start asks nothing and starts the shell.
start terminal {temp}\myproject
expect said Ready
refuse said Before axTerminal
