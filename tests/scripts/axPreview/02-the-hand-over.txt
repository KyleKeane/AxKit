# Workflow: Preview a file from another app
# axPreview, test plan section 2 (The hand-over, AP-1.2, AP-1.3), what can be driven from inside the windows
# (docs/axPreview/nvda-test-plan.md).
# 2.1 to 2.4 from axFile are in axFile's 04-hand-overs; 2.5, File Explorer's Open with axKit and Windows' default
# program, are outside the windows (manual).
# The run's own settings: no update check, whose network call logs an ERROR when GitHub cannot be reached.
file home\AxKit\axPreview.json {"checkForUpdates": false}
file README.md # Readme\n\nThe first window's file.
file plain.txt Plain text file, line 1.\nLine 2.

# 2.6, the first half: axpreview plain.txt while a window is open: a second process hands the file over and ends
# without a window of its own (launch waits for it to end); the open window shows it.
start preview {temp}\README.md
expect state "title":"README.md - axPreview"
launch preview {temp}\plain.txt
expect state "title":"plain.txt - axPreview"
expect focus {"name":"plain.txt","role":"Text","value":"Plain text file, line 1."}

# 2.6, the second half: axpreview --new README.md opens a second window while one is open.
start preview --new {temp}\README.md
expect state "title":"README.md - axPreview"
expect focus README.md
use 1
expect state "title":"plain.txt - axPreview"
expect focus plain.txt
