# axDown: AI help in a window (docs/axKit/ai-help.md AH-1, AH-6): off, the first ask opens the reminder at once (AH-1.3,
# 5.6.0) and Turn on records the agreement, turns Claude on and asks; the switch in the axKit menu, Claude;
# Shift+F1 asks Claude about this window and the answer is a notice with a field for more; the folders notice; off
# again for the scripts after this one, which share the run's home. Claude is a fake in cmd in the run's own settings
# folder, named by ai-help.json's relative claudePath, so the run never reaches Anthropic. No agreement is recorded
# beforehand here, unlike the scripts of earlier versions, so that the reminder's path runs.
file home\AxKit\axDown.json {"checkForUpdates": false}
file home\AxKit\ai-help.json {"enabled": false, "folders": [], "claudePath": "fake-claude.cmd"}
file home\AxKit\consent.json {"items":[]}
file home\AxKit\fake-claude.cmd @echo off\nmore > nul\necho {"type":"result","subtype":"success","is_error":false,"result":"The fake answer: Ctrl+Shift+W turns word wrap off and on.","session_id":"fake-3"}\n
file notes.md # Notes\n\nA line.
start down {temp}\notes.md
expect focus notes.md

# AH-1.3: off, Shift+F1 opens the reminder at once; Not now (Escape) leaves Claude off and asks nothing.
keys shift+f1
expect state "notice":"Before Claude helps in axKit"
keys escape
expect said ! Claude stays off
expect focus notes.md

# AH-1.2: the reminder again; Enter without the box says so; Space checks it; Turn on records the agreement, turns
# Claude on and goes on to the question.
keys shift+f1
expect state "notice":"Before Claude helps in axKit"
keys tab
expect said I understand
keys enter
expect said ! Check the box first
keys space
expect said ! checked
keys enter
expect said ! Claude on
expect focus Your question about this window
keys escape
expect focus notes.md

# AH-1.1: the switch, in the axKit menu, Claude: off, then on again at once since the agreement is recorded.
menu Use Claude in axKit
expect said ! Claude off
menu Use Claude in axKit
expect said ! Claude on

# AH-6.1: Shift+F1, the question field; Enter asks; the answer notice, the text first.
keys shift+f1
expect focus Your question about this window
type how do I turn word wrap off
keys enter
expect state Claude says
expect state The fake answer: Ctrl+Shift+W
# AH-6.3: Tab to the field for more; Enter asks in the same session.
keys tab
expect focus Ask more about this answer
type and back on
keys enter
expect state Claude says
# Escape closes the answer; the focus is back in the text.
keys escape
expect focus notes.md

# Escape in the question field asks nothing.
keys shift+f1
expect focus Your question about this window
keys escape
expect focus notes.md

# AH-2.3: the folders notice, none yet, naming Claude's working folder.
menu Folders Claude may read
expect state No folders yet
expect state axKit Claude
keys escape
expect focus notes.md

# Off again.
menu Use Claude in axKit
expect said ! Claude off
