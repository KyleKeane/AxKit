# Workflow: Move through a Markdown file by headings, lists and links
# axDown, test plan section 8 (Navigation), driven from inside the window (docs/axDown/nvda-test-plan.md, SPEC.md §9).
# The run's own settings: no update check, whose network call logs an ERROR when GitHub cannot be reached.
# long.md as manual_tests/prepare.ps1 makes it, with a shorter long line.
file long.md # Long Markdown file for navigation\n\nThe first paragraph, one line.\n\nThis line is longer than the window, so word wrap shows it on several rows and the caret test can tell. This line is longer than the window, so word wrap shows it on several rows.\n\n## Second heading, level 2\n\nA paragraph of two lines,\nthe second line of it.\n\n### Third heading, level 3\n\nLinks: [GitHub](https://github.com), a bare address https://www.example.com, and an angle address <https://example.org>.\nAn image, which is not a link: ![a picture](picture.png).\n\n## Lists\n\n- one\n- two\n  - two, nested\n- three\n\n1. numbered one\n2. numbered two\n\n## Quote and table\n\n> A block quote, line one.\n> Line two of the quote.\n\n| Name | Value |\n| --- | --- |\n| alpha | 1 |\n| beta | 2 |\n\n## Code\n\n```\n# not a heading, inside a fenced code block\n[not a link](https://example.com)\n> not a quote\n- not a list\n```\n\n#### Fourth level heading\n\n##### Fifth level heading\n\n###### Sixth level heading\n\nThe last paragraph of the file.

start down {temp}\long.md
expect focus long.md

# Goal: Move to the next heading
# 8.1: Ctrl+H to each heading, its line spoken; the one in the fenced code block skipped (8.2); at the last, "No next heading".
do Heading, Navigation, Next
expect said ! Second heading, level 2, heading level 2
# Check: Each heading is reached in turn, the fenced line skipped, and past the last No next heading is said
do Heading, Navigation, Next
expect said ! Third heading, level 3, heading level 3
do Heading, Navigation, Next
expect said ! Lists, heading level 2
do Heading, Navigation, Next
expect said ! Quote and table, heading level 2
do Heading, Navigation, Next
expect said ! Code, heading level 2
do Heading, Navigation, Next
expect said ! Fourth level heading, heading level 4
do Heading, Navigation, Next
expect said ! Fifth level heading, heading level 5
do Heading, Navigation, Next
expect said ! Sixth level heading, heading level 6
do Heading, Navigation, Next
expect said ! No next heading
expect state Line 50, Column 1 \u00B7
# Goal: Move back to the previous heading
# Ctrl+Shift+H back, the fenced line skipped again; at the first, "No previous heading".
do Heading, Navigation, Previous
# Check: Going back skips the fenced line again, and before the first No previous heading is said
do Heading, Navigation, Previous
do Heading, Navigation, Previous
do Heading, Navigation, Previous
expect said ! Code, heading level 2
do Heading, Navigation, Previous
do Heading, Navigation, Previous
do Heading, Navigation, Previous
do Heading, Navigation, Previous
expect said ! Long Markdown file for navigation, heading level 1
do Heading, Navigation, Previous
expect said ! No previous heading
expect state Line 1, Column 1 \u00B7

# Check: Arrow keys say nothing of axDown's own
# 8.3: plain arrow keys speak nothing of axDown's own.
keys down down down up right left end home
expect quiet 1000

# Goal: Move to a heading of one level
# 8.4: Ctrl+2, the next level-2 heading, other levels skipped; Ctrl+Shift+2 back; past the last, "No next heading level 2".
keys ctrl+home
do Heading level 2, Navigation, Next
expect said ! Second heading, level 2, heading level 2
# Check: A level skips the other levels both ways, and says when it has no heading left
do Heading level 2, Navigation, Next
expect said ! Lists, heading level 2
do Heading level 2, Navigation, Next
do Heading level 2, Navigation, Next
expect said ! Code, heading level 2
do Heading level 2, Navigation, Next
expect said ! No next heading level 2
do Heading level 2, Navigation, Previous
expect said ! Quote and table, heading level 2
do Heading level 4, Navigation, Next
expect said ! Fourth level heading, heading level 4
do Heading level 4, Navigation, Previous
expect said ! No previous heading level 4
# Goal: Move by heading from the menu
# Navigation, Next and Previous list Heading and Heading level 1 to 6 with their keys; the items do what the keys do.
expect commands "Heading, Navigation, Next, Ctrl\u002BH"
expect commands "Heading level 1, Navigation, Next, Ctrl\u002B1."
expect commands "Heading level 6, Navigation, Next, Ctrl\u002B6."
expect commands "Heading, Navigation, Previous, Ctrl\u002BShift\u002BH"
expect commands "Heading level 1, Navigation, Previous, Ctrl\u002BShift\u002B1."
expect commands "Heading level 6, Navigation, Previous, Ctrl\u002BShift\u002B6."
keys ctrl+home
menu Heading level 3, Navigation, Next
expect said ! Third heading, level 3, heading level 3
# Check: The other heading items of the menu do what their keys do
menu Heading level 1, Navigation, Previous
expect said ! Long Markdown file for navigation, heading level 1
menu Heading, Navigation, Next
expect said ! Second heading, level 2, heading level 2
menu Heading, Navigation, Previous
expect said ! Long Markdown file for navigation, heading level 1

# Goal: Move to the next link
# 8.5: Ctrl+K, the caret on the link's first character; a bare and an angle address count, an image does not, nor
# anything in the fenced code block.
keys ctrl+home
do Link, Navigation, Next
expect said ! GitHub, link
expect state Line 14, Column 8 \u00B7
# Check: A bare and an angle address are links, an image and the fenced block are not, and past the last No next link is said
do Link, Navigation, Next
expect said ! https://www.example.com, link
do Link, Navigation, Next
expect said ! https://example.org, link
do Link, Navigation, Next
expect said ! No next link
# Goal: Move back to the previous link
# Ctrl+Shift+K from inside a link: the link before it.
do Link, Navigation, Previous
expect said ! https://www.example.com, link
keys right right right
do Link, Navigation, Previous
expect said ! GitHub, link

# Goal: Move by list and by list item
# 8.6: Ctrl+L, "List with 3 items, one" at the first item; Ctrl+I, the next item's text, nested items included; a
# numbered list after a bulleted one is a second list.
keys ctrl+home
do List, Navigation, Next
expect said ! List with 3 items, one
do List item, Navigation, Next
expect said ! two
# Check: Nested items count, and a numbered list after a bulleted one is a second list
do List item, Navigation, Next
expect said ! two, nested
do List item, Navigation, Next
expect said ! three
do List item, Navigation, Next
expect said ! numbered one
keys ctrl+home
do List, Navigation, Next
do List, Navigation, Next
expect said ! List with 2 items, numbered one
do List, Navigation, Next
expect said ! No next list
do List, Navigation, Previous
expect said ! List with 3 items, one

# Goal: Move to a block quote or a table
# 8.7: Ctrl+Q, "Block quote, " and the first line; Ctrl+T, the table at its header line; nothing in the fenced code block.
keys ctrl+home
do Block quote, Navigation, Next
expect said ! Block quote, A block quote, line one.
# Check: Past the last block quote No next block quote is said
do Block quote, Navigation, Next
expect said ! No next block quote
# Goal: Move to a table
keys ctrl+home
do Table, Navigation, Next
expect said ! Table with 3 rows and 2 columns
expect state Line 32, Column 1 \u00B7
# Check: Past the last table No next table is said
do Table, Navigation, Next
expect said ! No next table
# Check: The previous table is one on a line before the caret
# From the header line itself the previous table is none: previous means on a line before the caret's.
do Table, Navigation, Previous
expect said ! No previous table
keys ctrl+end
do Table, Navigation, Previous
expect said ! Table with 3 rows and 2 columns

expect commands "List, Navigation, Previous, Ctrl\u002BShift\u002BL"
expect commands "List item, Navigation, Previous, Ctrl\u002BShift\u002BI"
