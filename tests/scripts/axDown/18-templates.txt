# Workflow: Put a template in at the caret: a link around the selected words, a table, and a template of your own
# axDown: Actions, Insert template (docs/axDown/SPEC.md AD-13; docs/axDown/nvda-test-plan.md, section 11). A template
# is text put in at the caret in the place of the selection, with the caret where the template says and the selected
# text carried in; the app's own come first, then axTemplate's templates checked for axDown or for every axKit
# app (TP-5); one checked for axJSON alone is not listed. Every one is a command, so the command palette finds them
# under the word "template". The test's template is one line: a file step turns every \n, and JSON's \u000a too,
# into a line break, which a JSON string may not hold.
file home\AxKit\axDown.json {"checkForUpdates": false}
file home\Documents\axKit\Templates\Meeting.json {"schema": "list.json", "Title": "Meeting", "Text": "# Meeting {caret}, present: {selection}", "axDown": true}
file "home\Documents\axKit\Templates\JSON only.json" {"schema": "list.json", "Title": "JSON only", "Text": "{}", "axJSON": true}
file doc.md axKit\n\nAda and Grace\n

start down {temp}\doc.md
expect focus doc.md

# Goal: Make the selected word a link and type its address
# The selected word becomes the link's text, and the caret waits between the round brackets.
keys shift+end
do Link, Actions, Insert template
expect said ! Link inserted
expect focus {"name":"doc.md","role":"Text","value":"[axKit]()"}
type https://example.org
expect focus {"name":"doc.md","role":"Text","value":"[axKit](https://example.org)"}

# Goal: Put in a table and type into its first cell
keys ctrl+end
do Table, Actions, Insert template
expect said ! Table inserted
type Name
expect focus {"name":"doc.md","role":"Text","value":"| Name |  |"}
expect text | --- | --- |

# Goal: Put in a template of your own from the command palette, with the selected words carried into it
# axTemplate's template Meeting, checked for axDown: the palette finds it by its name.
keys ctrl+home down down shift+end
do Command palette
type meeting
expect said Meeting
expect said Actions, Insert template
keys enter
expect said ! Meeting inserted
type of Monday
expect focus {"name":"doc.md","role":"Text","value":"# Meeting of Monday, present: Ada and Grace"}

# Check: The words insert template in the palette list every template
# The menu's name finds them all: the three of axDown's own and the one checked for axDown, not the one for axJSON.
do Command palette
type insert template
expect said Link, Actions, Insert template, 1 of 4
keys escape

# Check: One Ctrl+Z takes a template back
keys ctrl+z
expect said ! Undone
keys ctrl+z
expect said ! Undone
expect text Ada and Grace

# Check: In navigation mode no template is put in
keys ctrl+space
expect said ! Navigation mode
said
do Table, Actions, Insert template
expect said ♪ Edge
expect said ! Navigation mode: press Ctrl+Space to edit
