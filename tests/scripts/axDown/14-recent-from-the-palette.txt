# Workflow: Open a recent file or window from the command palette
# The recent lists in the command palette (docs/axKit/SPEC.md AX-10.2, the user's ask of 2026-11-13): Session, Open
# recent file, and the Window menu's Open windows and Recently closed are filled before the palette reads them, so
# that each entry is one search away, F1, a few letters, Enter. Shown in axDown; every app's Open recent and
# every Window menu are the same pieces.
file one.md # One\n\nThe first file.
file two.md # Two\n\nThe second file.

start down {temp}\one.md
expect state "title":"axDown file 
expect state \one.md","notice"
start down {temp}\two.md
expect state "title":"axDown file 
expect state \two.md","notice"
wait 500

# Goal: Open a recent file from the palette
# Open recent file from the palette: a few letters of the file's name, the first match said, Enter opens it here.
do Command palette
expect state "notice":"Command palette"
type one.md
expect said one.md
expect said Open recent file
keys enter
expect state "notice":null
expect state "title":"axDown file 
expect state \one.md","notice"

# Goal: Find another open window from the palette
# The Window menu's lists are there too: the other window by its title, and nothing recently closed yet.
do Command palette
type open windows
expect said \one.md, Window, Open windows
keys escape
expect state "notice":null

# Goal: Reopen a window that was closed
# Recently closed: the first window closes, and its file is the newest of the closed (before it two.md, which this
# window showed before it opened one.md). The close is waited for, so that the list holds it: read too early, the
# list was one entry short on some runs (2026-11-13). The entry is one search away and opens in a new window.
use 1
close
expect closed
use 2
do Command palette
type recently closed
expect said 1. one.md
expect said Window, Recently closed
keys enter
adopt
expect state "title":"axDown file 
expect state \one.md","notice"
expect focus "value":"# One
