# axDown: the theme items every window has (docs/axKit/theme.md TH-4, TH-5.3). The theme file lives in the run's own
# home, so nothing of the user's is touched: Reload with no file says what makes one; Edit theme file writes the
# template and opens it in axJSON; Reload then says so; Theme on toggles the file's switch and says which.
file home\AxKit\axDown.json {"checkForUpdates": false}
file home\AxKit\axJSON.json {"checkForUpdates": false}
file notes.md # Notes\n\nA line.
start down {temp}\notes.md
expect focus notes.md
menu Reload theme
expect said ! No theme file: axKit menu, Theme, Edit theme file makes one
menu Edit theme file
adopt
expect state theme.json - axJSON
expect text axkit-theme 1
close
use 1
menu Reload theme
expect said ! Theme reloaded
menu Theme on
expect said ! Theme off
menu Theme on
expect said ! Theme on
# TH-6: Ctrl+Shift+W writes the editors' word wrap into the same file; axJSON on it shows the value; back on for the scripts after.
keys ctrl+shift+w
expect said ! Word wrap off
menu Edit theme file
adopt
expect state theme.json - axJSON
expect text "wordWrap": false
close
use 1
keys ctrl+shift+w
expect said ! Word wrap on
