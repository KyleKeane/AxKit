# axDown: a line break typed is said, "new line" (docs/axKit/SPEC.md AX-7.8, docs/axDown/SPEC.md AD-2.8; report 1 of
# the reports repository). NVDA says nothing for Enter; the window says it, unless Options, Text, Say new line is off,
# which is written into the theme file of the run's own home, so nothing of the user's is touched.
file home\AxKit\axDown.json {"checkForUpdates": false}
file notes.md First line.

start down {temp}\notes.md
expect focus notes.md
keys ctrl+end
keys enter
expect said new line
type Second line.
expect focus {"name":"notes.md","role":"Text","value":"Second line."}
# Enter in the middle of a line splits it, and is said the same way.
keys home
keys right right right right right right
keys enter
expect said new line
expect focus {"name":"notes.md","role":"Text","value":" line."}

# The setting: off, then Enter puts the line break in silently; on again for the scripts after.
menu Say new line
expect said ! Say new line off
keys end enter
refuse said new line
menu Say new line
expect said ! Say new line on
keys enter
expect said new line

# Keys that put no line break in say nothing of it.
keys ctrl+home
keys down
expect quiet 1000
