# Workflow: Find a command in the menus, the palette and the help
# axDown, test plan section 6 (Menus and help), driven from inside the window (docs/axDown/nvda-test-plan.md).
# The run's own settings: the update check at start off, the switch this script turns on and off below.
file home\AxKit\axDown.json {"checkForUpdates": false}
file a.md # A file for the menus\n\nSome text here.\nMore text.

start down {temp}\a.md
expect focus a.md

# Check: Every menu item is in the command list with its shortcut
# 6.1 manual: Alt opens the menu bar, whose menu mode needs the foreground. Every item with its shortcut, as the
# palette reads them from the menus:
expect commands "Word wrap, Options, Text, F11, checked"
expect commands "Go to line, Navigation, F12"
expect commands "Heading level 2, Navigation, Next, Ctrl\u002B2."
expect commands "Undo, Actions, Ctrl\u002BZ"
expect commands "Command palette, Help, F1"

# Goal: Open the keyboard shortcuts
# 6.2: F1, the shortcuts notice, its first lines the rules of the keys (AX-8.18).
keys down right right
do Keyboard shortcuts
expect state "notice":"Keyboard shortcuts"
expect focus {"name":"Keyboard shortcuts","role":"Text","value":"## How the keys go
# Goal: Move through the keyboard shortcuts by heading
# h and Ctrl+H alike: the next section's heading; Shift+H back.
keys h
expect said ! In every window of axKit, heading level 2
# Check: Ctrl+H moves by heading as H does, and Shift+H goes back
keys ctrl+h
expect said ! axDown, heading level 2
keys shift+h
expect said ! In every window of axKit, heading level 2
keys h h
expect said ! The text, heading level 2
# Check: Moving by page or paragraph in the shortcuts says nothing
# Page Down and Page Up move a screen of its text, Ctrl+Down and Ctrl+Up a paragraph; the notice says nothing on them.
keys pagedown pageup ctrl+down ctrl+up
expect quiet 1000
# Goal: Find a word in the keyboard shortcuts
# Ctrl+F, wrap, Enter: the shortcuts text is back, then F3; Ctrl+F then Escape: the text is back.
keys ctrl+f
expect focus Text to find
type wrap
keys enter
expect focus Keyboard shortcuts
# 6.2 not checked here: the line with "wrap" selected; the focus answer's value is a wrapped row off in a wrapped text (see the report).
keys f3
expect focus Keyboard shortcuts
# Check: Escape in the find field brings the shortcuts back
keys ctrl+f
expect focus Text to find
keys escape
expect focus Keyboard shortcuts
expect state "notice":"Keyboard shortcuts"
# Goal: Close the keyboard shortcuts and go back to the text
# Escape closes the notice and the focus is back in the editor at the same place.
keys escape
expect state "notice":null
expect focus {"name":"a.md","role":"Text","value":"Some text here."}
expect state Line 3, Column 2 \u00B7

# Goal: Read the user guide
# 6.3: Help, User guide: this app's guide; the navigation keys move through it, spoken as in the editor.
menu User guide
expect state "notice":"User guide","noticeText":"# axDown user guide
keys ctrl+h
expect said heading level 2
# Check: A table the guide does not have is said as none
keys ctrl+t
expect said ! No next table
keys escape
expect focus a.md
# Goal: Hear the version of axKit
# axKit, About, Version names the version of axKit, the apps in their two kinds and the folders. The standalone apps
# are checked by how their list begins: a new app joins its end (axTemplate did on 2026-11-23, and the whole list
# written here failed); the whole sentence is BundleAbout's, tested there.
menu Version
expect state "notice":"axKit
expect state Standalone apps, which need only Windows: axStart, axFile, axClip, axTemplate, axDown, axJSON, axPreview, axMedia, axTask, axCalc, axProcess, axAutomate.
expect state axTerminal for your shell, axGIT for Git, axPass for KeePassXC, axClaude for Claude Code, axHelp for Claude Code, axMCP for MCP servers.
expect state Settings: 
expect state Logs: 
keys escape
expect focus a.md
# Goal: Read the licence, the attribution and the axKit guide
# About, Licence, Attribution and axKit guide open their notices; Escape closes each.
menu Licence
expect state "notice":"Licence"
keys escape
expect state "notice":null
# Goal: Read the attribution
menu Attribution
expect state "notice":"Attribution"
keys escape
expect state "notice":null
# Goal: Read the axKit guide
menu axKit guide
expect state "notice":"axKit guide"
keys escape
expect state "notice":null
expect focus a.md

# 6.4: the Window menu's Open windows and Recently closed are in the palette since 2026-11-13, played in
# 14-recent-from-the-palette; Alt+W needs the foreground (manual); Close all windows closes every axKit window on the
# desktop (manual).

# Goal: Turn the update check at start on or off
# 6.5: Options, Check for updates at start (the axKit menu until 2026-11-26), one switch for every app (bundle AX-3.1), a checked item that says its new state.
# Through the palette, which says the new state; the runner's menu step runs the item without saying it.
do Command palette
expect focus Search commands
type check for updates at start
expect said Check for updates at start, Options, 1 of 1
keys enter
expect said Check for updates at start, checked
# Check: The palette names the switch as checked and turns it off again
do Command palette
expect focus Search commands
type check for updates at start
expect said Check for updates at start, Options, checked, 1 of 1
keys enter
expect said Check for updates at start, not checked
expect focus a.md
# 6.5 manual: Copy diagnostics writes the user's clipboard; Open settings file starts an axJSON window the runner does
# not reach; the Markdown resources open the browser.

# Goal: Move through the commands of the palette
# 6.6: the command palette, with the caret in the middle of a line. With nothing typed it begins with the rules of
# the keys (bundle AX-10.2, 2026-11-26: palette and help in one); typed words find the commands.
do Command palette
expect state "notice":"Command palette"
expect focus Search commands
keys down
expect said ! A key alone moves and reads; with Shift, the other way, or select as you move., 2 of
keys up
expect said ! How the keys go, 1 of
# Check: The first line plays the edge sound when moved past
# Ctrl+Home at the first line: the low note and the first line again.
keys up ctrl+home
expect said ♪ Edge
expect said ! How the keys go, 1 of
type session
expect said New, Session, Ctrl+N, 1 of
keys down
expect said ! New window, Session, 2 of
keys down
expect said ! Open, Session, Ctrl+O, 3 of
# Goal: Run a command found by its name
keys ctrl+a
type wrap
expect said ! Word wrap, Options, Text, F11, checked, 1 of 1
keys down
expect said ♪ Edge
expect said ! Word wrap, Options, Text, F11, checked, 1 of 1
# Enter: the palette closes, the focus back in the editor at the same place, and the item's new state said.
keys enter
expect said Word wrap, not checked
expect focus {"name":"a.md","role":"Text","value":"Some text here."}
expect state Line 3, Column 2 \u00B7
expect commands "Word wrap, Options, Text, F11","Say new line, Options, Text
# Check: Word wrap is turned back on for the scripts after
# Back on: the setting is the run's theme file, which the scripts after this one share (docs/axKit/theme.md TH-6).
do Word wrap
expect said ! Word wrap, checked
# Check: A search with no match says so and runs nothing
# No match: "No commands match xyz"; Enter says it again and the palette stays; Escape: back, nothing run.
do Command palette
expect focus Search commands
type xyz
expect said No commands match xyz
keys enter
expect said No commands match xyz
expect state "notice":"Command palette"
keys escape
expect state "notice":null
expect focus a.md
expect quiet 1000
# 6.6 manual: save as, Enter opens the Windows Save as picker; Alt+H, P needs the menu bar's menu mode.
# Check: The command for a new axDown window is in the palette
# Alt+W, New window, axDown is in the palette; the recent lists are too, played in 14-recent-from-the-palette.
expect commands "axDown, axKit, Apps, Ctrl+F5"
# Check: A report's last actions name every command run
# docs/axKit/reports.md RP-4.1 (2026-11-25): a menu item that is no command of the list (Version) is written by its
# name as it is picked, and a key of the whole window (F4) by the name of its item and the key; the plain form holds
# the commands alone.
menu Version
expect state "notice":"axKit
keys escape
expect state "notice":null
keys f4
expect state "notice":"Report to axKit"
keys tab tab tab
expect focus "name":"What is sent with your report"
expect text : Version"
expect text : Send a report, F4"
keys escape
expect state "notice":null
expect focus a.md
