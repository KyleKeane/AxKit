# Workflow: Play or read a file from axFile
# axFile, test plan section 4: sound, video and reading, the hand-overs (docs/axFile/nvda-test-plan.md 4.1 to 4.5; AF-5).
# 4.1 is driven at the end: the window axFile starts is taken over by the runner (adopt), and a second Shift+Enter is
# handed to the axPreview window already open (AP-1.2).
# Manual (4.2): Ctrl+Enter in a folder of chapters starts axMedia.
# Manual (4.3): Ctrl+Shift+Q on two folders with media and Shift+F10, Q on a chapter start axMedia (behind this window).
# Manual (4.4): Shift+F10, A, M on a chapter or a folder and A, P on README.md start axMedia or axPreview.
# Manual (4.5): Enter with axMedia or axPreview made the default program needs Windows' Default apps.
file home\AxKit\axFile.json {"checkForUpdates": false}
file hand\README.md # Read me\nA text to read.
file hand\plain.txt A plain text.
file hand\no-media-here\only-text.txt Ctrl+Enter here says No sound or video files here.
mkdir hand\a-folder-for-not-a-file
start file {temp}\hand
expect focus "value":"a-folder-for-not-a-file, folder"
# A modifier key sent while the window still settles can lose its modifier (the channel); let it settle.
wait 500

# 4.2 Ctrl+Enter in a folder without media: "No sound or video files here".
keys down
expect focus "value":"no-media-here, folder"
keys enter
expect said ! no-media-here, 1 item, only-text.txt
keys ctrl+enter
expect said ! No sound or video files here
keys backspace
expect said ! hand, 4 items, no-media-here, folder

# 4.3 Ctrl+Shift+Q on a text file: "No sound or video files to add".
keys end
expect focus "value":"README.md"
keys ctrl+shift+q
expect said ! No sound or video files to add
# The Item menu's command does the same.
menu Add to axMedia's queue, Context
expect said ! No sound or video files to add

# 4.4 Open in axKit, axPreview on a folder: "Not a file".
keys home
expect focus "value":"a-folder-for-not-a-file, folder"
menu axPreview, Context, Open in axKit
expect said ! Not a file

# 4.1 Shift+Enter on README.md: an axPreview window on it, in front.
keys end
expect focus "value":"README.md"
keys shift+enter
adopt
expect state "title":"README.md - axPreview"
expect focus README.md
# Shift+Enter on plain.txt in axFile: the open axPreview window takes it; no second axPreview.
use 1
keys up
expect focus "value":"plain.txt"
wait 500
keys shift+enter
use 2
expect state "title":"plain.txt - axPreview"
expect focus plain.txt
# Shift+Enter on a folder: a new axFile window on that folder, not axPreview.
use 1
keys home
expect focus "value":"a-folder-for-not-a-file, folder"
wait 500
keys shift+enter
adopt
expect state a-folder-for-not-a-file
expect state axFile
