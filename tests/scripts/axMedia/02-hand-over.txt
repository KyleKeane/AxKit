# Workflow: Add files to the queue from another app
# axMedia: the hand-over (docs/axMedia/nvda-test-plan.md section 2; SPEC.md AM-1.1, AM-1.2, AM-1.3).
# The starts that open a window of their own (a play on a file, an add with no window open, --new beside an open
# window), and the hand-over proper: a start that hands its paths to the open window and ends without a window (the
# runner's launch, which waits for the process to end).
#
# Step 1, 1a, 2, 3 and 4 (first half): axFile's Open in axKit, Ctrl+Enter, Ctrl+Shift+Q, with axMedia open; a
# hand-over each, from another app's window (above), and the front window and NVDA's reading of it are tier 3.
# Step 5: Windows' default program and File Explorer are the system's, outside the test desktop.

file home\AxKit\axMedia.json {"checkForUpdates":false}
mkdir ch
silence ch\alpha.wav 30000
silence ch\beta.wav 30000
silence ch\gamma.wav 30000

# Step 4 (second half, AM-1.2, AM-D3): an add with no axMedia window open opens one with the queue and nothing
# playing; an add says nothing in axMedia (axFile says it).
# The app shows that window without activation; the runner activates it, as the user's switching to it would (every
# started window is, since 2026-11-01), and the queue is read through Ctrl+I, which the window takes from anywhere.
start media --add {temp}\ch
expect state "title":"axMedia"
expect quiet 1000
keys ctrl+q
expect said ! Nothing playing
keys ctrl+i
expect said ! alpha.wav, 1 of 3
close
wait 1500

# Step 1 as a start (AM-1.1): a file plays with its folder's media files around it, the file selected and marked;
# the window is named after the file from its first moment.
start media {temp}\ch\beta.wav
expect said ! Playing beta.wav
expect list ["alpha.wav","beta.wav (playing)","gamma.wav"]
expect focus beta.wav (playing)
expect state "title":"beta.wav - axMedia"
expect state "2 of 3, speed 1"

# Step 6 (first part): axmedia <file> with a window open: handed over, the open window plays it, no second window.
launch media {temp}\ch\alpha.wav
expect said ! Playing alpha.wav
expect state "title":"alpha.wav - axMedia"
# Step 6 (second part): axmedia --add <folder> with a window open: the open window's queue grows.
launch media --add {temp}\ch
expect list "Queue, 6 items"
expect list ["alpha.wav (playing)","beta.wav","gamma.wav","alpha.wav","beta.wav","gamma.wav"]

# Step 6 (third part): --new with a window open: a second window of its own, on the file, the first left alone.
start media --new {temp}\ch\gamma.wav
expect said ! Playing gamma.wav
expect list ["alpha.wav","beta.wav","gamma.wav (playing)"]
expect state "title":"gamma.wav - axMedia"
use 2
expect state "title":"alpha.wav - axMedia"
expect quiet 500
