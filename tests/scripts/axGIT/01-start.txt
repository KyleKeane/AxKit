# The update check off in the run's own settings (AXKIT_HOME): a network call, and its failure is a logged ERROR.
# The access layers' reminders agreed to already (AX-11.5): this script is about what comes after them.

# Goal: Open a repository
# 1.1 A repository is asked about once before git runs in it, also one where axGIT finds nothing of concern (AG-1.6,
# G1 of the review's sixth pass): the notice comes first.
start git {temp}\repo
expect state "notice":"This repository is not trusted yet"

# Check: A repository with nothing of concern is asked about once, and the notice says what trust means
# The notice says so and what trust means; Alt+T trusts it, one key more at a repository's first opening (the goal's
# count is the maintainer's to take in, docs/axKit/workflow-graph.md WG-3.4). Then the window is named after the
# repository, the Changes list focused on its first item.
expect state axGIT found nothing of concern in it.
expect state files itself and cannot promise that it found everything.
expect state Until you trust a repository, axGIT runs no git in it and reaches no server: it reads only the repository
expect state own files, where they lie (a repository on a share is read on the share), and the files on this computer its settings name.
expect state Keep it off closes the repository.
wait 1200
keys alt+t
expect said ! Trusted
expect state , axGIT,
expect state \repo","notice"
expect focus Changes, 2 files
expect focus Modified a.txt, unstaged
# Check: The window's command list holds every key of its own
# The window's command list: every key of its own in the F1 text, none shadowed (docs/axKit/app-kit.md AK-2.4).
# Asked once the list has its files: Context holds the commands of the row you are on, so before the repository
# is read it holds "Nothing selected", and the list of commands would be another (found 2026-11-22).
check commands
expect quiet 1500

# Goal: Move between the list and the details
# 1.2 Down: the next item only. Tab, Shift+Tab, F6, Ctrl+Tab between the list and the details.
keys down
expect said · Untracked new.txt
expect quiet 500
keys tab
expect said → Details (Text)
keys shift+tab
expect said → Changes, 2 files (List): Untracked new.txt
# Check: F6 and Ctrl+Tab switch between the list and the details as Tab does
keys f6
expect said → Details (Text)
keys ctrl+tab
expect said → Changes, 2 files (List): Untracked new.txt

# Check: The status bar holds the branch, its upstream and the counts
# 1.3 The status bar: the branch, its upstream state and the counts, then the path.
# (Plan: "main · up to date"; a repository without a remote reads "no upstream", AG-2.3. The NVDA+End reading itself is manual.)
# The runner matches "state" against the raw JSON, where the middle dot is ·, so the parts are matched apart.
expect state "status":["main
expect state no upstream
expect state 2 changed, 0 staged
expect state \\repo"]

# Goal: Go up to the repository and into another list
# 1.4b The three lists are rows of the repository (docs/axKit/framework.md FW-4.10): Left goes up, onto the list
# left, and at the top plays the edge sound; Right, or Enter, goes into the list you are on, read through git.
keys left
expect said ! repo, 3 lists, Changes, 2 files
keys left
expect said ♪ Edge
keys down
expect focus "value":"Log"
keys right
expect said ! Log, 2 commits.
keys backspace
expect said ! repo, 3 lists, Log, 2 commits
keys up
keys enter
expect said ! Changes, 2 files. Untracked new.txt

# Goal: Switch between the lists by their keys
# 1.4 The lists by Alt+1, 2, 3, each said with the row it is on; Alt+1 back on the row it had.
keys alt+1
expect said ! Changes, 2 files. Untracked new.txt
keys alt+2
expect said ! Log, 2 commits.
expect said Test: second
expect focus Log, 2 commits
keys alt+3
expect said ! Branches, 2. main, current, no upstream
# Check: Alt+1 comes back on the row the list had
keys alt+1
expect said ! Changes, 2 files. Untracked new.txt
expect focus Untracked new.txt

# Check: The commands on files say so on a commit, and the list stays
# 1.4a On a commit Space selects nothing (the edge sound: only files are selected), Delete says a commit is not
# removed, and Stage names the list its files are in.
keys alt+2
expect said ! Log, 2 commits.
keys space
expect said ♪ Edge
keys delete
expect said ! A commit is not removed here
keys ctrl+shift+s
expect said ! For the files of Changes: Alt+1
# Context holds the commands of the row you are on only (bundle AX-9.11), so Show diff is not offered on a commit.
expect commands Show the commit, Context
refuse commands Show diff, Context
expect focus Log, 2 commits
keys alt+1
expect said ! Changes, 2 files.
expect commands Show diff, Context
expect commands "Stage, Context, Ctrl+Shift+S"
expect commands "Discard changes, Context, Delete"
expect focus Changes, 2 files

# Goal: Close the window
# 1.6 Alt+F4 closes the window without a question (the runner's close is Alt+F4's path; that no question came is
# not checked: the runner has no step that expects a window to be gone).
close

# Check: A repository trusted once opens without the notice
start git {temp}\repo
expect focus Changes, 2 files
expect state "notice":null
close

# Check: A folder that is not a repository is said in a notice
# 1.5 Started on a folder that is not a repository: the notice naming the folder; Enter closes it; the title.
start git {temp}\plain
expect state Not a git repository
expect state plain is not inside a git repository
# The notice holds the answering keys for a second after it appears (KeyHold).
wait 1200
keys enter
expect state "notice":null
expect state "title":"axGIT"
