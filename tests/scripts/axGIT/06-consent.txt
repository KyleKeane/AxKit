# Workflow: Agree to the reminder before the first repository opens
# Needs: Git installed.
# axGIT: the reminder before the first repository opens (docs/axKit/SPEC.md AX-11.4, AX-11.5; the Owed list of
# docs/axKit/nvda-test-record.md). A fresh run's home has no consent, so the reminder comes first. With --nvda
# (nvda-pass.ps1) every expected line must be spoken by NVDA too.
run git init -q -b main repo
file repo\a.txt hello
start git {temp}\repo

# Goal: Agree to the reminder and open the repository
# The reminder's title and text, read on the focus.
expect said Before axGIT connects to Git
# Tab to the box, named with what it agrees to.
keys tab
expect said I understand that axGIT
# Enter before the box is checked connects nothing.
# The reminder holds its keys for a second, as every notice does that is no first result of a key (bundle AX-6.4).
wait 1100
keys enter
expect said ! Check the box first
# Space checks and unchecks, each said (AX-8.8).
keys space
expect said ! checked
keys space
expect said ! not checked
keys space
expect said ! checked
# Enter connects: the repository opens on its Changes list.
keys enter
expect focus Changes, 1 file
# Goal: Read what was agreed to on this computer
# About, Licence ends with what was agreed to on this computer (AX-11.8): this one, with the date and the version.
menu Licence
expect state What you have agreed to on this computer
expect state axGIT, Git,
# A notice a menu item opens holds its keys for a second (bundle AX-6.4, E3 of the fifth review of 2026-11-27).
wait 1100
keys escape
expect focus Changes, 1 file
close

# Check: The second start asks nothing
# The second start asks nothing.
start git {temp}\repo
expect focus Changes, 1 file
refuse said Before axGIT
