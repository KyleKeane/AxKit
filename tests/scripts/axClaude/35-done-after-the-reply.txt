# Workflow: Hear Done before the reply, and not after an interrupt
# Needs: tools/AxAutomate, which puts its own program in AXKIT_STANDIN for the stand-in of Claude Code (axAutomate's window does not); no Claude Code, no network and no model.
# axClaude, docs/axClaude/nvda-test-plan.md section 25 step 5 (docs/axClaude/events-and-grounding.md EG-5.6, EG-6.5 and
# section 4.2; 2026-11-17): "Done" is the core's. It is said when a turn has ended with its end marks and its bell and
# the last reply is in the conversation, and no longer 400 ms after any bell; since 2026-11-22 the word is heard first and that reply's words after it, in one utterance (SPEC.md FR-7.2a, the maintainer's choice). The stand-in
# (tools/AxAutomate/StandIn.cs) plays four ends as Claude Code 2.1.325 writes them, each step at a file the script
# makes, and writes the session file under the run's own folder as it goes. A turn whose reply's frame comes 80 ms
# after the bell: "Done" with its chime, then the reply's words. An interrupt, the end marks without a bell and the
# cut reply with its Interrupted row: no "Done". A bell alone, with a question's rows on the screen: the question,
# and no "Done" until the answer has ended the turn. A start mark and the end marks at once with no bell, the note
# Claude Code writes when it hands the prompt back: nothing at all. Speak replies is all lines, so that the reply's
# words are heard. A second window, with the file-only setting eventCore set to shadow, hears "Done" by the old rule,
# the bell and the settle.

# Goal: Hear Done, then the reply's words
# Claude takes the message up: the start mark and a working frame. Then the end marks and the bell, and the reply's
# frame 80 ms later: "Done" is said with the reply after it, and the Done chime plays.

file dn\go1 x
expect state Claude: working
file dn\go2 x

# Check: An interrupted reply ends without Done
# Ctrl+I while Claude works; Claude Code ends the turn with its end marks and no bell, then draws what it had
# of the reply and its Interrupted row: those are said, "Done" is not, and the status bar says ready.

keys enter
expect said Sent
file dn\go3 x
expect state Claude: working
keys ctrl+i
file dn\go4 x
expect said Interrupted
refuse said Done
refuse said ♪ Done
expect state Claude: ready

# Check: A bell with a question is the question, and Done waits for the turn's end
# The next message is sent seconds after the interrupt, as a person sends it (in the 600 ms after an interrupt it
# would be "Queued"). A tool asks for permission: the bell rings with no end mark before it, and the question is
# shown in the message field's place; no "Done". Its keys are held for a second: the answer goes after that. The
