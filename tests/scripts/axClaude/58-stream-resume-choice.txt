# Workflow: Choose an earlier conversation to resume, over Claude Code's stream
# Needs: tools/AxAutomate, which puts its own program in AXKIT_STANDIN for the stand-in of Claude Code (axAutomate's window does not); no Claude Code, no network and no model.
# axClaude, docs/axClaude/stream-mode.md SM-8.5 (2026-11-26): a --resume with no id (New session's "Choose a
# conversation to resume") opens Claude Code's own list of conversations, a screen the stream does not have. A window
# the stream feeds asks with a list of its own instead: the folder's conversations, newest first, each named by its
# date and the first words of its first message; the choice starts Claude Code with --resume and that conversation,
# whose earlier part is shown from its file. The first window's stand-in writes two session files where Claude Code
# keeps them (tests/fixtures/records/plain-turn.jsonl, then stream-session.jsonl, the newer); the second window, in
# the same folder, is started with a bare --resume.
file home\AxKit\axClaude.json {"replySpeech":"none","interruptForQuestions":true,"workingMusic":false,"backgroundAlert":false}
file home\AxKit\consent.json {"items":[{"app":"axClaude","target":"Claude Code","version":"0","when":"2026-10-31T00:00:00"}]}
mkdir st
file claude.cmd @set "CLAUDE_CONFIG_DIR=%~dp0home\.claude"& "%AXKIT_STANDIN%" standin --stream turn --session plain-turn,stream-session %*
start claude {temp}\st --claude {temp}\claude.cmd --source stream
expect said Start Claude Code in this folder?
wait 1500
keys tab
keys enter
expect said Ready
# The folder's question held its keys, so the message field's Enter waits a second after it closes (bundle AX-6.4).
wait 1100
close
wait 2000

# Goal: Hear the folder's conversations, newest first
start claude {temp}\st --claude {temp}\claude.cmd --source stream -- --resume
expect said Start Claude Code in this folder?
wait 1500
keys tab
keys enter
expect focus : Remember this word for later: kiwi.
expect list : Name three colours of a rainbow.
expect state Claude: starting
wait 3000

# Goal: Start nothing when no conversation is chosen
keys escape
expect said Cancelled
do Conversation
expect text No conversation was chosen, so Claude Code was not started.
expect state Claude: stopped

# Goal: Choose the conversation and go on with it
do Force Claude to restart
expect focus : Remember this word for later: kiwi.
wait 3000
keys enter
expect said Sent: 1,
expect said Ready
do Conversation
expect text # Input 1 from previous session
expect text you: Remember this word for later: kiwi.
expect text claude: Noted. I will remember it.
refuse text Name three colours of a rainbow.
