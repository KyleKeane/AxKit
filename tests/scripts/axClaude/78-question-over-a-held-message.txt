# Workflow: Get a message back when Claude asks while its prompt row still shows it
# Needs: tools/AxAutomate, which puts its own program in AXKIT_STANDIN for the stand-in of Claude Code; no Claude Code, no network and no model.
# axClaude, docs/axClaude/SPEC.md D33 ("One message in flight", the seventh review of 2026-11-27, K2). Claude Code can
# drop a message's Enter and then draw a question under the draft that still holds it. Until that review a question
# counted as Claude Code having taken the message: "Sent" stood, the conversation showed it as sent, and it was not.
# Now the last reading of the row before the question decides: it still showed the message, so the message comes
# back into the field, and the conversation shows it as not sent; a row seen bare before the question means taken.
# The stand-in (tools/AxAutomate/StandIn.cs) draws what is typed, drops every Enter ("dropEnters"), writes every key it
# reads to a file ("keys"), and draws a question at a file of the script's, under the draft, without clearing.
file home\AxKit\axClaude.json {"replySpeech":"none","interruptForQuestions":true,"workingMusic":false,"backgroundAlert":false}
file home\AxKit\consent.json {"items":[{"app":"axClaude","target":"Claude Code","version":"0","when":"2026-10-31T00:00:00"}]}
mkdir qh
file claude.cmd @"%AXKIT_STANDIN%" standin "%~dp0scenario.json" %*
file scenario.json {"version":"2.1.332 (stand-in)","dropEnters":99,"keys":"keys.txt","steps":[{"frame":["claude: started","auto mode on (shift+tab to cycle)","$"],"clear":true},{"waitFile":"go1"},{"frame":["","Permission Required: Create file","alpha.txt","Do you want to create alpha.txt?","1. Yes","2. No","Select with numbers [1-2]. Then Enter to submit or Escape to cancel:"]},{"idle":true}]}
file expected.txt held message<Enter>\n
start claude {temp}\qh --claude {temp}\claude.cmd -- --model haiku --effort low
expect said Ready
wait 1000

# Goal: Get a message back that Claude asked over before it took it
# A question drawn while the row still shows the message gives the message back.
type held message
keys enter
expect said Sent
file qh\go1 x
expect said Not sent: Claude asks something while its prompt row still showed the message; the message is back in the message field
expect focus 1. Yes, Create file alpha.txt
expect state Claude: waiting for your answer
run fc /b qh\keys.txt expected.txt

# Check: The conversation shows the message as not sent
do Conversation
expect text Not sent: Claude began to ask something while its prompt row still showed your message after its Enter. The message is back in the message field.
refuse text # Input 1
