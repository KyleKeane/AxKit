# Check: The Enter of the first answer, pressed again, does not answer the second file
# docs/axKit/SPEC.md AX-6.4 ("A question that arrives by itself"; the second review of 2026-11-27). Enter pressed twice
# reaches the second file's list within a second of its appearing, before NVDA has said more than "Question": the
# list starts on "1. Yes", and until that day the Enter approved the file unheard, since a list that followed the
# user's own answer held no keys. Every control of the area now holds its answering keys for a second after it is
# shown, whatever came before, and the press it took is heard: the sound of a refusal, and nothing sent.
# (A key held down is another matter, which no script can press: its repeats never answer, ControlAreaHoldTests.)
keys enter
expect said ♪ Edge
refuse said Sent:
expect focus 1. Yes, Create file beta.txt

# Goal: Allow the second file once its question was heard
# The second that the list held its keys is long over.
