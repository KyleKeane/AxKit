# Workflow: Change Claude Code's mode and use the window's commands over the stream
# Needs: tools/AxAutomate, which puts its own program in AXKIT_STANDIN for the stand-in of Claude Code (axAutomate's window does not); no Claude Code, no network and no model.
# axClaude, docs/axClaude/stream-mode.md SM-5 (2026-11-17): what the window sends over Claude Code's stream. The
# stand-in plays the recording of a mode change and a turn in the new mode (tests/fixtures/streams/mode.jsonl): the
# window's mode key writes the request for the next mode, Claude Code answers with it, and the window says the mode in
# the screen's words. A command that has no meaning without Claude Code's screen says one sentence, the same everywhere.
# A restart ends the process by the end of its input and starts a new one.
file home\AxKit\axClaude.json {"interruptForQuestions":true,"workingMusic":false,"backgroundAlert":false,"replySpeech":"all"}
file home\AxKit\consent.json {"items":[{"app":"axClaude","target":"Claude Code","version":"0","when":"2026-10-31T00:00:00"}]}
mkdir st
file claude.cmd @"%AXKIT_STANDIN%" standin --stream mode %*
start claude {temp}\st --claude {temp}\claude.cmd --source stream
# The folder's question comes first (stream-mode.md SM-7.1): Enter is no, so the yes is its own button.
expect said Start Claude Code in this folder?
wait 1500
keys tab
keys enter

# Goal: Go to Claude Code's next permission mode
expect said Ready
# The folder's question held its keys, so the message field's Enter waits a second after it closes (bundle AX-6.4).
wait 1100
expect state Claude: ready | manual mode on
do Next permission mode
expect said accept edits on
expect state Claude: ready | accept edits on

# Goal: Send a message in the new mode
type Write the file
keys enter
expect said Sent
expect said Done. claude: written
do Conversation
expect text tool: Write (C:\work\probe-mode.txt)
expect text claude: written

# Check: A command that needs Claude Code's screen says so
do Send queued messages now
expect said Not with the stream source
menu Ctrl+D
expect said Not with the stream source
keys ctrl+o
expect said Not with the stream source
# Choose the model is a list of the window's own over the stream, made from the first request's answer, which in
# this recording lists no models (50-stream-choices.txt has one that does).
menu Choose the model
expect said Claude Code has not listed them. Type /model and a value as a message

# Check: Nothing is interrupted or sent when there is nothing
do Interrupt
expect said Nothing to interrupt
do Message field
keys enter
expect said Nothing to send

# Goal: Restart Claude Code
do Force Claude to restart
expect state Force Claude to restart?
keys enter
expect said Restarting
expect said Ready
do Conversation
expect text System: Restarting Claude
