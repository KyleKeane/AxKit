# Needs: tools/AxAutomate, which puts its own program in AXKIT_STANDIN for the stand-in of Claude Code (axAutomate's window does not); no Claude Code, no network and no model.
# axClaude, docs/axClaude/stream-mode.md SM-7.7 (2026-11-26): in plan mode Claude asks to leave it with its plan, and
# Claude Code asks its permission tool, the relay, as the screen asks "Ready to code?". The window asks with the plan as
# the question's text, after the caution (bundle rule 11), the screen's three answers with the no that keeps planning
# where the list starts, and one that opens the whole plan; a yes sends the mode the work goes on in. The stand-in plays
# the recording of a plan approved with manual approval and carried out (tests/fixtures/streams/plan.jsonl, Claude Code
# 2.1.332): the mode key's request takes the run to plan mode as the recording's did.
file home\AxKit\axClaude.json {"interruptForQuestions":true,"workingMusic":false,"backgroundAlert":false,"replySpeech":"all"}
file home\AxKit\consent.json {"items":[{"app":"axClaude","target":"Claude Code","version":"0","when":"2026-10-31T00:00:00"}]}

# Goal: Read the whole plan before answering
keys end

# Claude carries the plan out and asks before its edit, as manual mode does.
