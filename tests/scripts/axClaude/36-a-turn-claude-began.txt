# short line of why the music plays and a reply comes that nobody sent for: "Claude goes on by itself", once for the
# turn, never interrupting, with its switch under Options, Announcements. The core decides it, from the turn's prompt in
# the session file, which Claude Code writes with the source system. The stand-in (tools/AxAutomate/StandIn.cs) plays
# three turns as Claude Code 2.1.325 writes them, each step at a file the script makes, and writes the session file
# under the run's own folder as it goes: a turn of a message the user sent, which says nothing of the kind, and two
# turns Claude Code began, the first with the switch on, the second with it off. Speak replies is all lines, so that the
# reply's words are heard after the line. No hooks: the session file is found by the first message sent.
