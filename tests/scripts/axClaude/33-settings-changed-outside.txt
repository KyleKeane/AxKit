# axClaude, SPEC Appendix C and the bundle's repair R-53 (docs/axKit/repairs.md): the place of Claude Code in the
# settings, claudePath, is sealed; one that another program wrote into the file is not used, and the window says so
# as a system line in the conversation. The stand-in of 29-stand-in-turn.txt only shows the prompt here.
# The refusal is logged as an error.
allow error was changed outside axKit and is not used
file home\AxKit\axClaude.json {"replySpeech":"none","interruptForQuestions":true,"workingMusic":false,"backgroundAlert":false}

file claude.cmd @"%AXKIT_STANDIN%" standin "%~dp0scenario.json" %*

start claude {temp}\st --claude {temp}\claude.cmd -- --model haiku

# A change of an option saves the settings, and so seals them: from now on this install has sealed the file.

# Check: A place of Claude Code another program wrote into the settings is not used
# The closed window writes its settings as it goes: the file is written over only after that, without the seal.
wait 2000

start claude {temp}\st --claude {temp}\claude.cmd -- --model haiku
