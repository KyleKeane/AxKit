# Workflow: Answer a set of two questions from Claude
# Needs: Claude Code signed in, the network and a live model (Haiku): a step that waits for Claude's words can fail when the model words it differently.
# axClaude: a set of two questions (docs/axClaude/nvda-test-plan.md section 12 step 19). The first question reads
# itself; after its answer the second cuts in and reads itself, with nothing of the first read again.
# The options this script was written with, named: a new install's defaults differ since 2026-11-21 (SPEC.md D10).
file home\AxKit\axClaude.json {"replySpeech":"none","interruptForQuestions":true,"workingMusic":false,"backgroundAlert":false}
mkdir q
# The access layers' reminders agreed to already (AX-11.5): this script is about what comes after them.
file home\AxKit\consent.json {"items":[{"app":"axClaude","target":"Claude Code","version":"0","when":"2026-10-31T00:00:00"},{"app":"axGIT","target":"Git","version":"0","when":"2026-10-31T00:00:00"},{"app":"axTerminal","target":"Windows PowerShell","version":"0","when":"2026-10-31T00:00:00"},{"app":"axTerminal","target":"PowerShell 7","version":"0","when":"2026-10-31T00:00:00"},{"app":"axTerminal","target":"Command Prompt","version":"0","when":"2026-10-31T00:00:00"},{"app":"axTerminal","target":"Git Bash","version":"0","when":"2026-10-31T00:00:00"},{"app":"axPass","target":"KeePassXC","version":"0","when":"2026-10-31T00:00:00"}]}
start claude {temp}\q -- --model haiku --effort low
try said trust
iffound wait 1500
iffound keys enter
expect said Ready
# The field by its whole name: the trust question's list is still in the area for a moment after Ready (message.txt).
expect focus "name":"Message to Claude"
type Use your AskUserQuestion tool once, with two questions: which colour I prefer, red or blue, and which season I prefer, summer or winter.
keys enter
# Said by the focus on the list the question names, after the word that interrupts (SPEC.md FR-7.4b, 2026-11-26).
expect said → Question 1 of 2
wait 1500
keys enter
expect said → Question 2 of 2
said
wait 1500
keys enter
said
# After the last answer the app submits Claude's review itself, and the message field comes back (the set's last
# question stayed in its place until 2026-10-23 and took the next message as its answer).
expect focus Message to Claude
