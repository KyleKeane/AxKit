# Workflow: Read a workflow's marks and open its file as text
# axAutomate, docs/axAutomate/user-guide.md beyond 01 to 03: "The folder" (type the start of a name; Backspace comes
# back up), "A workflow's steps" (the marks after a step's sentence: goes on if it fails, reports, otherwise 1 step;
# a step's details), "Running workflows" (a workflow's details say Cannot run) and "Keys" (Ctrl+J, the workflow's file
# as text; Session, Refresh; F1; Ctrl+N and F2 refused; Ctrl+R before any run); plan steps 1.2, 1.3, 3.1, 3.3 and 3.4
# (docs/axAutomate/nvda-test-plan.md; SPEC.md AU-4), run by tools/AxAutomate on a desktop of its own.
# Not here: Ctrl+Q in a step's details, which the guide says reads every line at once (plan step 3.2); it says the
# selected line alone today, which is the report's to name and not a step to write as passing.
# Session, Refresh has no key here: F5 runs (AU-D8). The window lists Refresh without a key, so do Refresh chooses
# the menu item; until 2026-11-21 the listing named Refresh on F5 and do Refresh started a run of every workflow.
mkdir flows
file flows\01-script.txt # A script.\n\nstart down\nwait 100\nclose
file flows\02-marks.workflow.json {"format": "axkit-workflow 1", "title": "Marks", "covers": "a made-up plan, section 1", "steps": [{"do": "start", "arguments": "down"}, {"do": "expect said", "text": "x", "on failure": "continue"}, {"do": "menu", "name": "Close all windows", "on failure": "continue", "report": "Not closed"}, {"do": "expect said", "text": "y", "otherwise": [{"do": "close"}]}]}

start automate {temp}\flows
expect state "title":"axAutomate flows"
expect focus 01-script, workflow, 3 steps

# Goal: Find a workflow by typing the start of its name
type mar
expect focus Marks, workflow, 5 steps

# Goal: Read what a workflow covers and whether it can run
# Tab on a workflow: its details as lines, what it covers and, for one this version cannot run, the first reason
# (here its third step, which goes on if it fails; 02-run has the one with otherwise steps).
keys tab
expect focus {"name":"Details of Marks","role":"List","value":"Title: Marks"}
expect list "Title: Marks","Covers: a made-up plan, section 1","Steps: 5"
expect list "Format: a workflow file","Cannot run: step 3 goes on when it fails; in this version only an expect said may","Right or Enter goes into its steps"
keys escape
expect focus Marks, workflow, 5 steps

# Goal: Read the marks after a step's sentence
# The rows: an expectation that may not come, a step that goes on if it fails and reports, a step with an otherwise
# block, and the block's step right after it, numbered under it.
keys right
expect said ! Marks, 5 steps, 1. Start down
keys down
expect focus 2. Expect said: x, may not come
keys down
expect focus 3. Choose the menu item Close all windows, goes on if it fails, reports
keys down
expect focus 4. Expect said: y, otherwise 1 step
keys down
expect focus 4.1 otherwise: Close the window

# Goal: Read what a step does when it fails and what it reports
# Tab on a step: its number, what it does, its value, what happens when it fails, its report and its file.
keys up up
expect focus 3. Choose the menu item Close all windows, goes on if it fails, reports
keys tab
expect focus {"name":"Step 3","role":"List","value":"Step 3"}
expect list "items":["Step 3","Does: menu","Name: Close all windows","On failure: continue, the run goes on","Report: Not closed","In 02-marks.workflow.json"]
# Check: Right and Left change nothing in a step's details and play the edge sound
keys right
expect said ♪ Edge
keys left
expect said ♪ Edge
expect focus {"name":"Step 3","role":"List","value":"Step 3"}
keys escape
expect focus 3. Choose the menu item Close all windows, goes on if it fails, reports

# Check: A new item and a rename are refused in this version
keys ctrl+n
expect said ! This version views and runs the workflows; changing them comes later
keys f2
expect said ! This version views and runs the workflows; changing them comes later

# Check: A workflow not run yet has no report
keys ctrl+r
expect said ! No report yet: F5 runs the workflow
expect state "notice":null

# Check: Backspace comes back up to the folder
keys backspace
expect said ! flows, 2 workflows, 0 folders, Marks, workflow, 5 steps
expect focus Marks, workflow, 5 steps

# Goal: Read the folder again after a workflow was added
# A script written into the folder while the window is open; Session, Refresh lists it, the selection kept.
file flows\03-new.txt # A script added while the window is open.\n\nstart down\nclose
do Refresh
expect said ! Refreshed: flows, 3 workflows, 0 folders
expect list "03-new, workflow, 2 steps"
expect focus Marks, workflow, 5 steps

# Goal: Read every key of the window
keys f1
expect state "notice":"Keyboard shortcuts"
expect state F5: run the workflow you are in, on a desktop of its own
keys escape
expect state "notice":null
expect focus Marks, workflow, 5 steps

# Goal: Open a workflow file as text in axJSON
# Ctrl+J on a workflow file: an axJSON window on the file (a window of this run).
keys ctrl+j
adopt
expect state "title":"axJSON file 
expect state \02-marks.workflow.json","notice"
close
use 1

# Goal: Open a script as text in axDown
# Ctrl+J on a script: an axDown window on the file.
keys home
expect focus 01-script, workflow, 3 steps
keys ctrl+j
adopt
expect state "title":"axDown file 
expect state \01-script.txt","notice"
close
use 1
expect focus 01-script, workflow, 3 steps
