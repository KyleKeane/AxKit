# Workflow: Move through axCalc's history and find in it
# axCalc, docs/axCalc/nvda-test-plan.md, what 01-basics and 02-answers-variables-history leave of sections 3, 4 and 6:
# 3.1 and 4.2 (the bases of the last answer and of the line you are on), 4.1 (Up and Down read one line), 4.5 (F3 and
# Shift+F3 the next and the one before, "Not found"), 4.7 (the question's text with the number of entries), AC-5.7
# (the history's letters, as in axClaude's conversation: a for the next answer), 6.1 (the text size) and 6.4 (the
# palette). SPEC AC-4.1, AC-5. The history is a text since 2026-11-22 (docs/axKit/framework.md step 9; a list until
# then, where Delete removed an entry and a typed character found one). Not run: 3.3 and 4.2's Ctrl+Shift+C (the
# user's clipboard), 4.6 (the Windows save dialog).
file home\AxKit\axCalc.json {"keepHistory": false}

start calc
expect focus Expression
type 255
keys enter
expect said ! 255
# Goal: Hear the last answer in other bases
# 3.1 F8 in the field: the last answer in other bases.
keys f8
expect said ! 255, hex FF, binary 1111 1111, octal 377
# Check: Each answer is said alone as it comes
type 10+1
keys enter
expect said ! 11
type 2.5*2
keys enter
expect said ! 5
type 10*3
keys enter
expect said ! 30

# Goal: Move through the history one line at a time
# 4.1 The history, a text: the caret on the newest answer's line; Up reads one line at a time, nothing announced.
keys shift+tab
expect focus "name":"History","role":"Text","value":"10*3 = 30"
keys up
expect focus "value":"2.5*2 = 5"
keys up
expect focus "value":"10+1 = 11"
keys up
expect focus "value":"255 = 255"
expect quiet 1500
# Check: Up on the first line stays on it
keys up
expect focus "value":"255 = 255"

# Goal: Hear the answer of an entry in other bases
# 4.2 F8 in the history: the answer of the line you are on, not the last one (AC-4.1).
keys f8
expect said ! 255, hex FF, binary 1111 1111, octal 377
keys down
keys f8
expect said ! 11, hex B, binary 1011, octal 13

# Goal: Move from answer to answer with a letter
# AC-5.7 The history's letters are a conversation window's: a is the next answer and Shift+A the one before; l says
# the line's number.
keys a
expect focus "value":"2.5*2 = 5"
keys shift+a
expect focus "value":"10+1 = 11"
keys l
expect said ! Line 2 of 4

# Goal: Find the next and the previous match in the history
# 4.5 Find from the line you are on: the next match, F3 the one after it round the end, Shift+F3 back.
keys ctrl+f
expect state "notice":"Find"
type 10
keys enter
expect state "notice":null
expect focus "value":"10*3 = 30"
keys f3
expect focus "value":"10+1 = 11"
# Check: Find next goes round the end of the history
keys f3
expect focus "value":"10*3 = 30"
# Goal: Go back to the previous match
keys shift+f3
expect focus "value":"10+1 = 11"
# Check: A text no line holds is said as not found
# A text no line holds: "Not found", the caret kept.
keys ctrl+f
expect state "notice":"Find"
type zebra
keys enter
expect said ! Not found
expect focus "value":"10+1 = 11"

# Check: Delete removes nothing from the history
# AC-5.6 The history is a text: Delete on a line leaves it, and Clear history is the way to empty it.
keys delete
expect focus "name":"History","role":"Text","value":"10+1 = 11"

# Check: The clear question counts the entries and Escape keeps them
# 4.7 The question says how many entries go; Escape keeps them and gives the history back.
keys ctrl+shift+delete
expect state "notice":"Clear the history?","noticeText":"The 4 entries cannot be brought back."
keys escape
expect state "notice":null
expect focus "name":"History","role":"Text","value":"10+1 = 11"

# Goal: Go back to the field from the history
# 4.4 Escape: back to the field.
keys escape
expect focus "name":"Expression","role":"Text","value":""

# Goal: Change the text size
# 6.1 The text size, up and back.
keys ctrl+plus
expect said ! Text size
keys ctrl+minus
expect said ! Text size

# Goal: Hear the bases from the command palette
# 6.4 The palette: "bases" says the bases of the last answer.
keys f1
expect state "notice":"Command palette"
type bases
keys enter
expect said ! 30, hex 1E, binary 1 1110, octal 36
expect state "notice":null
expect focus "name":"Expression"
