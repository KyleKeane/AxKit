# Workflow: Calculate and reuse earlier answers
# axCalc: the field, the answer, the history and its keys (docs/axCalc/nvda-test-plan.md; SPEC AC-3 to AC-6). Every
# key here is a command of the window's one list (docs/axKit/app-kit.md AK-2), so this script is also the check that the
# list does what the key switch did before it.
file home\AxKit\axCalc.json {"keepHistory": false}

start calc
# Check: The window's command list holds every key of its own
# The window's command list: every key of its own in the F1 text, none shadowed (docs/axKit/app-kit.md AK-2.4).
check commands
expect focus Expression

# Goal: Calculate an expression
# AC-6.1: Enter answers, the answer said alone, the field emptied.
type 1920*1080*4
keys enter
expect said ! 8294400
expect focus "name":"Expression","role":"Text","value":""

# Goal: Empty the field
# AC-6.1: Escape empties a field with text ("Cleared") and says "Empty" on an empty one.
type 2+2
keys escape
expect said ! Cleared
keys escape
expect said ! Empty

# Goal: Go on from the last answer
# An expression starting with an operator continues from the last answer (AC-3).
type /2
keys enter
expect said ! 4147200

# Goal: Hear the last answer in other bases
# Ctrl+Q says the last answer; Ctrl+I the answer in other bases.
keys ctrl+q
expect said 4147200
keys ctrl+i
expect said hex

# Goal: Put an earlier expression back in the field
# Tab to the history, a text since 2026-11-22 (docs/axKit/framework.md step 9): the caret on the newest answer's
# line; Enter puts that line's expression back in the field (AC-5.2).
keys tab
expect focus "name":"History","role":"Text","value":"/2 = 4147200"
keys enter
expect focus "name":"Expression","role":"Text","value":"/2"

# Goal: Go back from the history to the field
# In the history Escape goes back to the field, which still holds what it held. Delete removes nothing: the history
# is a text, and Clear history empties it (AC-5.6).
keys tab
expect focus "name":"History"
keys escape
expect focus "name":"Expression","role":"Text","value":"/2"
keys tab
keys delete
expect focus "name":"History","role":"Text","value":"/2 = 4147200"
keys escape
keys escape
expect said ! Cleared

# Check: Find in the history opens and closes
# Ctrl+F finds in the history; Escape closes the find.
keys ctrl+f
expect state "notice":"Find"
keys escape
expect state "notice":null

# Goal: Read the keyboard shortcuts
# F1: the shortcuts end with the Notices section every window of axKit has (2026-11-09); Escape closes the text.
keys f1
expect state "notice":"Keyboard shortcuts"
expect text Notices
keys escape
expect state "notice":null

# Goal: Get to the end and the start of the field with the page keys
# Bundle AX-8.2 (2026-11-23): Page Down goes a screen and then to the very end of the text, Page Up to its start;
# pressed there again, the edge sound. The field is one row here, so one press gets there.
type 12+34
keys home
keys pagedown
type 0
expect focus "name":"Expression","role":"Text","value":"12+340"
keys pagedown
expect said ♪ Edge
keys pageup
type 9
expect focus "name":"Expression","role":"Text","value":"912+340"
keys pageup pageup
expect said ♪ Edge
keys escape
expect said ! Cleared

# Goal: Open another app with its key
# Bundle AX-8.18 rule 6 (2026-11-23): Ctrl with a function key opens a standalone app from any window, each group
# on its block of four keys; Ctrl+F5 is axDown, the first of documents and media.
keys ctrl+f5
adopt
expect state "title":"axDown Untitled"
close
use 1
expect focus Expression
