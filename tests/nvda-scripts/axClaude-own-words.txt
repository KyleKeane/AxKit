# The question takes the focus from the message field: NVDA reads it by the list's name, then the first answer.
file ow\go1 x
expect focus "role":"List"
expect spoken What should happen?
expect spoken Propose one per window
wait 3000
spoken

# The arrows to Other: NVDA says it.
keys down
expect spoken Nothing where nothing fits
keys down
expect spoken Other
wait 1000
spoken

# The question drawn again with a row changed: NVDA reads the list again, on Other, not the first answer.
file ow\go1b x
expect spoken What should happen now?
expect spoken Other
refuse spoken Propose one per window
wait 2000
spoken

# Enter: Other is named as sent, and the first answer is not.
said
keys enter
expect said Sent: 3, Other. Your words next
refuse said Sent: 1
refuse spoken Propose one per window
wait 1500
spoken

# Claude Code asks for the words: NVDA reads the field by its name, the answer chosen in it.
file ow\go2 x
expect focus You chose Other. Your answer
expect spoken You chose Other. Your answer
wait 2500
spoken

# The words are typed and sent: NVDA says them.
type tulips by the old stone wall
keys enter
expect said Sent: tulips by the old stone wall
wait 2000
file ow\go3 x
