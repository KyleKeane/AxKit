# Workflow: Put a template into another window from axTemplate's launcher, with NVDA
# NVDA tier (docs/axKit/automation.md, tier 3): Enter in the launcher hides it, gives the front back to the window
# that had it, and pastes the template there (docs/axTemplate/SPEC.md TP-4.1); the caret goes back to its mark
# (TP-2.3), what was on the clipboard stands for {clipboard} and is on it again afterwards (TP-4.3); Ctrl+Enter takes
# that window's selection first (TP-4.2). Only a desktop with a real front window shows that, so it is run only with
# --nvda, at the user's word, with the user away from the keyboard. The other window is axDown on a file of the
# run's own; the launcher's hotkey is one nobody uses.
file home\AxKit\axTemplate.json {"checkForUpdates": false, "hotkey": "Ctrl+Alt+Shift+F7", "sayFirstMatch": false}
file home\Documents\axKit\Templates\Thanks.json {"schema": "list.json", "Title": "Thanks", "Text": "Dear {caret}, thank you for {clipboard}"}
file home\Documents\axKit\Templates\Link.json {"schema": "list.json", "Title": "Link", "Text": "[{selection}]({caret})"}
file notes.md A line.
start down {temp}\notes.md
expect spoken notes.md

# Goal: Put a template in where the caret was
# The line is copied first, so that the clipboard holds a text of the run's own; then a new line for the template.
keys shift+end
keys ctrl+c
keys end
keys enter
# The launcher is the run's second window; it remembers axDown as the window it came up over.
start template --launcher
expect spoken Search templates
type thanks
keys down
expect spoken Thanks, 1 of 1
keys enter
# The paste, the Left keys and the clipboard given back are over in under a second. The runner's use takes the
# front with an Alt key held for 50 ms, so it waits until they are done: Left keys that met that Alt were taken as
# Alt+Left, and the caret landed short (the NVDA pass of 2026-11-23).
wait 1500
use 1
# The caret waits at its mark: what is typed now lands there.
type friend
expect text Dear friend, thank you for A line.

# Check: What was copied before is on the clipboard again
keys end
keys ctrl+v
expect text thank you for A line.A line.

# Goal: Put a template in around what is selected
# Ctrl+Enter copies the selection in the other window, and the template takes its place.
keys enter
type word
keys shift+home
launch template --launcher
use 2
expect spoken Search templates
type link
keys down
expect spoken Link, 1 of 1
keys ctrl+enter
# The copy in axDown, the paste, the caret and the clipboard, all before the runner's Alt of use.
wait 2000
use 1
type address
expect text [word](address)
