# Workflow: Read a long reply with Say all while Claude writes
# NVDA tier (docs/axKit/automation.md, tier 3): Say all over axClaude's conversation while Claude streams a long reply
# (docs/axClaude/SPEC.md FR-3.3, 2026-11-09): the view holds its output while NVDA moves the caret as it reads, so the
# reading goes on; the lines are there once it stops. Run only with --nvda, the user away. NVDA+A starts Say all in NVDA's laptop layout, which this computer uses (NVDA+Down, the desktop layout's, only read the next line here).
file home\AxKit\axClaude.json {"checkForUpdates":false}
file home\AxKit\consent.json {"items":[{"app":"axClaude","target":"Claude Code","version":"0","when":"2026-10-31T00:00:00"}]}
mkdir read
start claude {temp}\read -- --model haiku
expect said trust
wait 1500
keys enter
expect said Ready
wait 2000
# A first reply gives the conversation forty lines to read; the second streams while NVDA reads them from the top.
type Write a numbered list of 40 lines, each naming a different vegetable with one full sentence about it, numbered 1 to 40, nothing else.
keys enter
expect said Done
wait 2000
type Now a numbered list of 120 lines, each naming a different fruit with one full sentence about it, numbered 1 to 120, nothing else.
keys enter
wait 1500
keys ctrl+2
keys ctrl+home
# Say all from the top while the second reply streams in for half a minute: NVDA reads down through the banner, the
# first input and the forty lines of the first reply, and must not be cut while the view holds the new lines; its speech
# is in the report (the two spoken dumps). The window's own Done is not spoken by NVDA while it reads, so the status
# bar is what tells that the turn ended.
keys nvda+a
expect spoken Input 1
wait 20000
spoken
wait 20000
spoken
wait 15000
expect state Claude: ready
# Once the reading has stopped and the hold has passed, every line is in the text: the list's last line.
wait 5000
keys ctrl+end
expect text 120.
