# Workflow: Hear the stream's new answers and refusals
# Needs: tools/AxAutomate's stand-in of Claude Code's stream (AXKIT_STANDIN); no Claude Code, no network and no model. Run only with --nvda, the user away.
# NVDA tier (docs/axKit/automation.md, tier 3): what NVDA says for the first round of docs/axClaude/stream-equivalence.md
# section 5 (docs/axClaude/nvda-test-plan.md section 26, steps 9 and 10; stream-mode.md SM-5.8, SM-7.4). A typed
# command of Claude Code's screen alone says "Not with the stream source" and the command; a tool call's question has
# "No, and tell Claude why" second, which opens a field named with the answer chosen, and the words go as they are
# typed. The stand-in plays the recording of a refused Write call (tests/fixtures/streams/denied.jsonl). The windows'
# own scripts check the same without NVDA: tests/scripts/axClaude/55-stream-refused-why.txt and
# 56-stream-typed-commands.txt.
file home\AxKit\axClaude.json {"replySpeech":"none","interruptForQuestions":false,"workingMusic":false,"backgroundAlert":false}
file home\AxKit\consent.json {"items":[{"app":"axClaude","target":"Claude Code","version":"0","when":"2026-10-31T00:00:00"}]}
mkdir st
file claude.cmd @"%AXKIT_STANDIN%" standin --stream denied %*
start claude {temp}\st --claude {temp}\claude.cmd --source stream
expect said Start Claude Code in this folder?
wait 1500
keys tab
keys enter
expect said Ready
wait 2000
spoken

# A command of the screen alone: said with the command, and nothing is sent.
type /help
keys enter
expect said Not with the stream source: /help
expect spoken Not with the stream source
wait 1500
spoken
keys ctrl+a delete

# The tool call's question: NVDA reads it by the list's name, then the first answer.
type Write the file
keys enter
expect focus "role":"List"
expect spoken Claude asks to use Write
expect spoken No
wait 3000
spoken

# Down to the second answer: NVDA says it with the call's file.
keys down
expect spoken No, and tell Claude why
wait 1000
spoken

# Enter: the field for the words, named with the answer chosen.
keys enter
expect said Sent: 2, No, and tell Claude why. Your words next
expect focus You chose No, and tell Claude why. Your answer
expect spoken You chose No, and tell Claude why. Your answer
wait 2500
spoken

# The words go, and NVDA says them.
type Use notes.txt instead
keys enter
expect said Sent: Use notes.txt instead
expect spoken Sent: Use notes.txt instead
wait 2000
