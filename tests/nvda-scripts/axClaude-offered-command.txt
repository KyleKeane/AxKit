# The question as it arrives: who offers, the command whole, then the answer the list starts on.
mcp call axkit_offer_command {"window":"{window}","command":"echo heard-by-ear","reason":"A check by ear.","details":"echo: prints its words"}

# Each answer is read as the arrows reach it.

keys down

wait 1000
spoken

# The concern's field is read by its instruction; Escape comes back to the list, which is read again by its name.
keys enter

wait 2500
spoken
keys escape
expect focus 5. No, and report a concern about it

spoken

# The explanation: a notice read by its title; closed, the list is read again.

# To the conversation and back: the conversation reads as usual, and the list by its name again.

spoken
