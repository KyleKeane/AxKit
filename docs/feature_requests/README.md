# Feature requests and bugs

The maintainer's feature requests and bugs are issues of the reports repository, https://github.com/KyleKeane/AxKit-reports, since 2026-11-07, as everyone's reports are: F4 in any window of axKit sends one (docs/axKit/reports.md). That repository is private since 2026-11-14, and a report is read with `tools/ReportKey` (docs/axKit/reports-setup.md section 5); axTask's GitHub lists, which showed them until then, were removed (reports.md section 7). The lists Features and Bugs this folder held became issues 1 to 4 there.
