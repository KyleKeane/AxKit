# Feature requests and bugs

The maintainer's own notes of what to change in axKit, feature requests and bugs alike, as Markdown files in this
folder, so that they are in the repository and a session of the assistant finds them. GitHub's issues and pull requests
are for outside contributors (`CONTRIBUTING.md`) and wait, as the tracker of this work, until there are users; until
then this folder is the tracker (the maintainer's choice, 2026-11-06).

- A running file such as `thoughts.md`, or one file per app or topic; one ask or one bug per line or paragraph, in the
  maintainer's words, with the app's name and the date when they matter.
- An ask that becomes work moves to its place: a new app to `docs/axkit/plan.md`, Still to come; a change to an
  existing app to that app's spec (axClaude's §12 To do, or a line in the app's spec) and then to the code. The line
  here is removed in the same commit, so that what is left here is what is still open.
- Nothing personal in these files (`CLAUDE.md` rule 6): no path of this computer, no password, nothing pasted from
  axPass or a terminal. `PrivacyTests` reads the repository for an e-mail address or an account path.
