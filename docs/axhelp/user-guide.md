# axHelp user guide

axHelp is a question from anywhere or about this window, answered by Claude, made for screen reader users.

## Install

axHelp is part of axKit. Installing axKit (see the axKit guide in the axKit menu, About) gives you a Start menu entry `axKit axHelp` and a console command `axhelp`. Any axKit window starts one too: Alt+A, New window, axHelp.

## Start

The window ends its title in "- axHelp", and the focus starts in its list.
