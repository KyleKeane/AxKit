# axDescribe user guide

axDescribe is the window in front described by Claude, made for screen reader users.

## Install

axDescribe is part of axKit. Installing axKit (see the axKit guide in the axKit menu, About) gives you a Start menu entry `axKit axDescribe` and a console command `axdescribe`. Any axKit window starts one too: Alt+A, New window, axDescribe.

## Start

The window ends its title in "- axDescribe", and the focus starts in its list.
