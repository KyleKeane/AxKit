# AxPreview.Core, the pure code

Everything of axPreview that needs no window: whether a file reads as text, the renderers that turn every kind of file into the content pane's text, and the Details list's lines. Unit tested in `tests/AxPreview.Tests` over bytes and a temporary folder. The spec is `docs/axpreview/SPEC.md` ("SPEC.md" below); the app side is `src/AxPreview`, with its own `CLAUDE.md`; the window is the text editor shell in `src/AxKit.Forms` in its read-only mode. The bundle rules are in the root `CLAUDE.md`.

## Commands

```
dotnet test tests/AxPreview.Tests/AxPreview.Tests.csproj
```

## Where things are

- `TextSniff` and `Refusal` (SPEC.md AP-2.2): `IsText` (the editors' kinds by extension, an empty file, a UTF-16 mark, else no zero byte and under five per cent control characters in the first eight kilobytes; from axFile's preview pane, 2026-10-22), `Refuse` (the notice's title and text for a text over the editors' 32 MB, null when it opens: every other file opens since 2026-10-24; a file that cannot be read is left to the shell's reader, which reports it).
- `Renderers`, `Renderer`, `Rendered` and `WayOut` (SPEC.md AP-7, 2026-10-24): the table, first match by extension or first bytes, the last taking every file: `Text` (`TextDocument.Read`, with the counts), `Document` (`OfficeText`: Word's `word/document.xml`, PowerPoint's `ppt/slides/slideN.xml` in number order, OpenDocument's `content.xml`; headings as Markdown headings, list items with "- ", table rows with tabs; all the parts of a document limited to 32 MB unpacked, counted on the stream as it is read (S-47), an XML reader that refuses a DTD and resolves nothing (S-48); a part named with backslashes found too, as Windows PowerShell 5.1 writes them), `Archive` (`ZipListing`, the directory only, names with forward slashes, File Explorer's order, the first `MaxEntries` (1,000) listed and the rest as one "and N more" line, with a Shown line in the contents, 2026-11-09), `Media` (a picture's text through `PictureText` in two steps, `Rendered.Later` and `Said`; a short text for sound and video), `Readable` (`ReadableText`: runs of four or more printable characters, ASCII and UTF-16, from the first 32 MB). `Render` falls back to the readable text, with the reason as its first line, when a document or zip cannot be read. Tested in `RenderersTests` over files made in a temporary folder.
- `PictureText` (SPEC.md AP-7.2 item 4, AP-D11; 2026-11-09): a picture's text through Windows' reader, `Windows.Media.Ocr`, which Windows PowerShell 5.1 loads as a WinRT type: `Script` (written beside the logs by `EnsureScript`), `Start` (Windows PowerShell by its full path, S-1), `Read` (the run as lines or a problem: exit 2 is no recognition language, `NoLanguage`), `RecognizeAsync` (the one outside call), `FirstPage` (shown at once, with `Rendered.Later` for the finished page) and `Finished` (the text under a line naming the picture, or none, or why, with the sentence `Said`). Tested in `PictureTextTests`, the reader itself on `tests/fixtures/picture-text.png` when this Windows has a language.
- `FileDetails` (SPEC.md AP-6.2, 2026-10-24): `Lines` (the File, Contents and Windows' details groups under their heading lines), `FileGroup` (the size through `AxKit.Core/FileSize`, the type name through `SHGetFileInfoW`), `Attributes`, `WindowsGroup` (the property store through `SHGetPropertyStoreFromParsingName`, each property's description through `PSGetPropertyDescription`, kept when viewable and not already in the File group, its value through `PSFormatForDisplayAlloc` with Windows' direction marks taken out; on an STA thread of its own, given up after five seconds), `ValueOf` and `NameOf`. Tested in `FileDetailsTests`. The settings are the editors' `EditorSettings` in `AxKit.Core`, in `axpreview.json`.
