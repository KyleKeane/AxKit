`AnsweredWait` (2026-11-27, pure, `AnsweredWaitTests`: when a question the user answered on the screen is over, by `Question.Content`, the signature and the lines between, so that the next one is shown though it reads the same; when the window's settle waits; and `Unheard`, `AnswerLapsed` and `Replaced`, SPEC.md D33: nothing answers what was not put to the user, a key that answered nothing stops counting, an unanswered question replaced by one that shows other rows is over, by `Question.Content`, which `StandingQuestionTests` holds steady over the recordings; `StillWaits`: a control answers only while what it was shown for waits), `QueuedWrite` (2026-11-27, pure: whether what a write still in the window's queue was for is over when its turn comes, a message when Claude Code has begun to ask or asks something else than the question it was sent into, a typed answer when something else waits; since the fourth review of that day a message's Enter only on a positive check, the prompt row showing the message, and the Enter sent again by `EnterAgain`; since the fifth, `MessageEnter` answers a `WriteCheck` of `AxKit.Core/Pty`, "not yet" an answer of its own until the longest wait, and a question that cannot be read is no other one; `SessionModel.PromptHolds` takes only Claude Code's draft form, `$` and its no-break space or the shell mode's mark, and the whole message read from the row's start to the cursor's row, blanks aside, `PromptDraft` the draft itself, every recording under tests/fixtures checked; since the sixth, `MessageFirst`, `EnterAgain`, `Taken` and `ClearGivenBack` keep a message in flight until Claude Code has taken it, `StillWaitsOn` binds nothing to a question that cannot be read, and `PromptHolds` compares without blanks and hidden characters and takes the mark of a paste, `ClaudeCodeTexts.PastedMark` (named PastedWithoutBlanks until the seventh review))

## The rule now (the seventh and eighth reviews, 2026-11-28)

A text is typed only onto a bare row and its Enter goes only when the row shows it; once the Enter has gone the message is Claude Code's and no check gives it back (the eighth review, M-A: the seventh's K1 and K2 gave back on what the row showed after the Enter, and /permissions and /tasks, which draw their screen in the row's place in the frame that takes them, were given back, taken as they were).

- `MessageFlight`: one message in flight, the checks the window wires (`Writes`, which the window queues and the tests queue the same; `First`, `Rest`, `Enter`, `Again`, `Taken`), with what they remember between them (`Typed`, `Entered`, `EnteredAgain`, `Done`, `LeftOnRow`, `Remark`) and the reason of an over before the Enter (`Why`, a `GivenBack`: `Asked`, `NotShown`, `NotBare`, `NotDrawn` for a row not drawn, M3, and the window's `Interrupted`, `Stopped`, `Failed`). `own` for the user's own message. `MessageFlightTests` flies the recordings' messages and slash commands through the window's `WriteQueue` with the window's own frame rule (a frame ends at the cursor shown or after 100 ms of quiet; L2 of the eighth review, which dropped the test's extra frame ends) and the recorded clock, each chunk cut at random: every one whose Enter went is taken; clear's last message and long-message's two come back before their Enter, since the recording's own Enter, 150 ms after the text, came before the window's check reached the frame that showed the draft.
- `QueuedWrite.Taken`: skipped once the row is bare, when Claude Code asks, for a message sent into a question, and at the limit whatever the row shows; never over. `MessageFlight.Taken` sets `LeftOnRow` for any draft still on the row at the limit, with `ClaudeModel.PromptRemark`, Claude Code's own line about it (`ClaudeCodeTexts.RemovedForReview` or `RemovedFromPrompt`). `QueuedWrite.EnterAgain` never for a text with a hidden character (K4).
- "Holds a hidden character" is `AxKit.Core/DisplayText.HoldsHidden`, a line end and a tab aside (M1: a message of two lines got no second Enter), asked by `MessageFlight.Hides` and `SessionModel.PromptHolds`. `PromptHolds(text, hiddenAside)`: the user's own message is compared without its hidden characters; any other text with them, held only by a row that shows it with them (K4).
- `SessionModel` reads the prompt row as the last frame's end showed it (K3): `KeepFrame` keeps the rows' text and the cursor's row, arrays reused frame after frame; `PromptRowReadingTests` replays the recordings as the window gets them, cut at random, and `MessageFlightTests` holds it at a flight's outcome. After /clear the prompt row keeps its cells (`AxKit.Core/Vt/Screen.DetachRows`' kept row, read by `UnlinedText` until a line is made for it). The last frame that asked nothing (KeepAskFree and PromptHeldBeforeAsk until the eighth review, K2) is no longer kept.
- `SessionModel.PromptHolds` (K4, L3): both sides read as `Squeezed` makes them, a run of blanks one blank, so that a blank between two words on one row counts and only a row join may lose one; paste marks of one draft numbered in order, a number of nine digits at most (`ClaudeCodeTexts.PastedMark`; L1 of the eighth review: a longer one threw).
